# 高地与土坡战场 · 1.3.0

日期：2026-09-29。原有六张地图继续保留，新增三个不同规模的真实高度战场。

| 地图 | 队伍 / 据点 | 地形与路线选择 |
| --- | --- | --- |
| 叠翠台地 | 1v1 / 11 | 四条宽土坡通往 4.5 米中央台地；正面抢塔与南北低地包抄形成不同推进路线 |
| 盘山双关 | 2v2 / 15 | 南北 4.5 米台地经第二段坡道连接 8 米山脊要塞；山脚与外沿道路允许换线 |
| 云冠盆地 | 3v3 / 21 | 5 米环形高地、六处外坡、两处内坡、腹地工坊与两端水塘，连接三条战线 |

双方出生点、地形和据点配置沿左右轴镜像。高度影响通行与真实行军距离；土坡可上，陡崖不可跨越。高地本身不额外增加伤害或射程，炮塔和技能依旧按水平半径计算。

## 地形与画面

地图使用保存的原生场景、网格和 Resource，可直接在 Godot 编辑器中查看。台地与土坡由同一份高度定义驱动，建筑放在完整平面上；坡脚、坡顶和崖角保留精确接缝。崖壁采用土色分层与轻微起伏，并在坡脚搭配碎石、蕨草和树林，保持现有积木风格。

道路沿坡面连续铺设；编队展开后逐兵采样脚下高度，浮空和网络平滑修正保留相对地面的高度。地面技能圈、火焰、烟雾、火星和队友鼠标同步适配；塔圈仅投影到地形，保持阵营色、旋转虚线和柔和透明度。
