# 交互配色验证（2026-09-14）

修复战争图鉴列表悬停时的白字，并检查共享主题、肉鸽编队与招募、设置及三种战斗面板的同类问题。补齐原生状态字色，提亮浅绿按钮底板，保留现有卡通素材、几何布局与战斗主面板分组。

## 验证方法与结果

`tests/ui_contrast_test.gd` 实例化实际场景，读取局部覆盖与父级 Theme 的最终字色。覆盖 32 个控件、186 种状态，404/404 检查通过。检查普通、悬停、选中、按下并悬停、焦点、禁用、下拉菜单及输入状态；在纹理中心区域取 9 点，叠加原始透明度和底板，包含按钮悬停 1.10、按压 0.91 的颜色调制。未知 3D 底景分别以黑、白底合成，取较低结果。

| 测量项 | 最低对比度 |
|---|---:|
| 全部被测活动状态 | 4.849:1 |
| 全部被测禁用状态 | 3.120:1 |
| 图鉴列表悬停 | 7.524:1 |
| 图鉴列表选中后悬停 | 5.175:1 |
| 三份独立战斗主题的活动状态 | 5.400:1 |
| 三份独立战斗主题的禁用状态 | 3.952:1 |

以上为被测控件正文区域的资源采样结果，不代表全部场景像素或所有浮动战场文字的无障碍认证。活动文字目标为 4.5:1，禁用文字的 3:1 是项目自定要求。

`tests/rogue_interaction_color_test.gd` 使用原生鼠标事件实际悬停和选中名册、招募候选、招募券、页签与下拉框，检查不可支付的事件选项仍处于禁用状态；33/33 检查通过，生成 8 张截图。图鉴另以鼠标实际复现“骑士选中、轻骑兵悬停”及选中后悬停，文字均保持深灰绿。已人工查看图鉴和肉鸽交互截图。

编队错误与成功说明由旧浅色调制改为直接设置深红、深绿字色；实测正文对比度分别为 6.30:1、6.69:1。

使用 `tools/build_windows.ps1 -PackOnly` 更新 Windows 包；导出日志无错误，包内目录与资源检查 233/233 通过。ZIP 包含启动程序、最新 PCK、运行说明、字体许可和两个诊断辅助文件。
