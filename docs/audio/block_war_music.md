# 积木战争原创配乐候选

## 当前方向：以《夺桥疾行》A 版为来源的节奏与能量调整

用户认可《夺桥疾行》A 版带节奏引入的感觉，同时反馈 V2 太吵、过快，能量起伏和旋律仍需改善。本轮三组均通过 Suno 的 Cover 功能，直接使用这首 [A 版](https://suno.com/song/6e2f5724-2dd4-4804-93c9-2a05ec7109ce) 作为音频来源。

- 引入：先保留四小节、约 7–8 秒的拨弦与轻打击乐节奏，再进入主旋律。
- 速度：本轮目标 120–132 BPM；保持攻防的节奏感，减少连续快速音符。
- 旋律：单一中音区乐器领奏，保留原曲主题轮廓，减少装饰音；短句、长音与休止交替，回答乐器只在空隙进入。
- 能量：较轻引子 → 适中主题 → 八小节减少伴奏 → 短暂提升 → 回落，通过配器和强弱形成起伏。
- 音色：减少尖锐双簧管类音色、嘹亮铜管、镲片铺底、滚奏与过多声部叠加，保留小提琴、木管和拨弦的灵巧感。

## V2 记录（保留 A 版作为改编来源）

V2 根据首版缺少作战感的反馈，强化了速度和主题旋律。以下是当时的设计目标；最新速度、引入与能量要求以 V3 为准。

- 节奏目标：140–152 BPM，保持明确的快速推进感。
- 主旋律：前两小节内进入，采用容易记住的 4–8 小节主题，通过清晰重复与变奏形成记忆点。
- 战斗表达：上行号召、短促回答、紧张和声与有力解决，让旋律呈现冲锋、争夺、反击；鼓点为旋律提供支撑。
- 段落：A-A-B-A，短暂对比后快速回归主旋律，避免长前奏、慢速铺垫和失去旋律的鼓点段落。
- 音色：保留灵巧、鲜明的小军团气质，突出号角、弦乐和木管的主题呼应。
