# 积木战争原创配乐候选

配乐方向取自轻巧、俏皮、质朴的策略游戏氛围，以木管、拨弦和小型打击乐表现经营、行军与协作。使用原创旋律提示词，没有上传参考游戏音频。

## 生成设置

- Suno 工作区：`积木战争 · 原创配乐候选`。
- 模型：v6；每个方向计划生成两个版本。
- 目标时长：3 分钟；Weirdness：30%；Style Influence：75%；Variety：Normal。
- Lyrics 留空，提示词要求纯器乐；Max Mode 与 Personalize 关闭。
- 统一限制人声、合唱、重型预告片鼓点、突兀变速及宏大终止式，为游戏指令与战斗音效留出空间。

完整英文提示词与排除词保存在 [block_war_music_prompts.json](block_war_music_prompts.json)。
