# 高级战斗单位完整设计报告（整数版）

数值版本：`integer-v1`，2026-09-18。**全套整数数值及此前五种高级单位已获认可，长矛兵与弓箭手的帽子衔接修正已通过。本批高级弩手、高级骑士已完成建模和试装，等待验收。每批制作两个，确认后才开始下一批。** 本批记录见[高级弩手与高级骑士验收](advanced-crossbow-knight-batch.md)。

## 一、范围与设计目标

包括：剑士、盾卫、长矛兵、弓箭手、弩手、火枪手、骑士、轻骑兵、战象。排除全部攻城器、农民、工程兵、牧师和英雄。

首版只在自由沙盘放置、战争图鉴展示。图鉴在原兵种页面切换普通／高级，没有重复条目；没有高级招募、研究、电脑招募或联机入口。战斗分类、攻击通道、职责三者继续独立，高级只是兵种等级，不增加一套克制类别。

本报告以当前项目资源为基线，包括战象**360生命、32攻击、2人口**，盾卫145生命。不会回退到早期讨论中的26攻击战象、5人口战象或180生命普通盾卫。

目标是生命和主要输出大致增加15%～25%，以20%为中心，同时使“普通对普通”和“高级对高级”的有效命中次数尽量接近。**本次数值设计中的生命、攻击、穿甲、护甲、类别附伤全部使用整数**；攻击间隔、移动速度等连续量仍可使用小数。这是本轮方案选择，没有将其写成全项目永久规则。

优先级依次为：保留兵种职责和克制关系；保持同级战斗节奏；使主要属性接近20%；在整数门槛下逐项调整。不得为了凑百分比，顺带增加射程、攻速、移速、范围攻击或新技能。

## 二、《帝国时代》的参考与本项目取舍

官方科技树把兵种升级线与铁匠铺等通用科技分开，并展示骑士向游侠、民兵向冠军剑士的演进。本项目借鉴“保留兵种身份，强化其装备与战斗职责”，通用攻防科技仍按原规则独立叠加。[《帝国时代II》官方科技树教学](https://www.ageofempires.com/learn-to-play/civilizations-game-modes-aoe2/)

精锐并不是全属性统一乘1.2的公式。例如官方更新162286将普通／精锐怯薛生命分别调至120／145，并单独调整精锐征服者攻击和升级费用。这说明等级与费用可以按具体兵种分别平衡；120→145约20.8%只是一个例子，不能推导出所有精锐都遵循20%。[《帝国时代II》官方更新162286，2025-12-02](https://www.ageofempires.com/news/age-of-empires-ii-definitive-edition-update-162286/)

《帝国时代IV》赛季九历史预览将精锐军队战术的生命加成方向改成护甲，同时把类别附伤纳入攻击强化；火药科技也曾从基础伤害转向对特定目标的附伤。借鉴的是“基础伤害、护甲和克制附伤一起考虑”，这里不是引用当前线上版本数值。[官方赛季九预览12.0.1974](https://www.ageofempires.com/news/age-of-empires-iv-season-nine-update-preview-12-0-1974/)

“同级互攻次数基本不变”是本项目的设计目标，不是《帝国时代》官方承诺。原来的1.2浮点缩放虽然让无科技81组算例全部一致，却产生26.4攻击、1.2护甲、3.6穿甲；本报告**替代并废止**那套方案，采用明确的整数设计。

当前实际伤害公式：

```text
有效护甲 = max(0, 对应攻击通道的护甲 + 防御科技 - 固定穿甲)
每击伤害 = max(1, 基础攻击 + 攻击科技 + 最大匹配类别附伤 - 有效护甲)
击杀次数 = ceil(目标最大生命 / 每击伤害)
首次命中后的理论击杀时间 = (击杀次数 - 1) × 攻击间隔
```

附伤匹配多个标签时取最大值，不叠加；超出的穿甲不转换为额外伤害。攻城器近战护甲不吃防御科技，农民与建筑不吃军队攻防科技。计算直接调用游戏中的 `DamageResolver`，不使用另一套模拟公式出报告。

## 八、逐兵种设计理由

### 高级剑士：135生命，11攻击，2／2护甲，对骑兵+6

生命和攻击分别提升22.7%、22.2%，仍是通用前排。135生命让高级弓箭手、弩手打它仍为13次，高级火枪手仍为5次。两类护甲保持2：直接加到3是50%的护甲变化，会明显拖长盾卫、长矛兵等低攻击单位的互攻。强化耐久由生命承担，对骑兵的6点附伤继续保持补充反骑兵能力。

### 高级盾卫：180生命，7攻击，3／8护甲

生命提升24.1%，取目标区间较高端；攻击只提升16.7%，远程护甲增加1点，仍是承受箭雨的前排。相较普通，面对同级弓箭手37→36发、弩手29→30发、火枪手9→9发，三种远程武器的区别保留。近甲保持3，避免互砍拖至60次。没有格挡概率、嘲讽或击退。

### 高级长矛兵：90生命，7攻击，1／1护甲，对骑兵+24

生命提升20%，基础攻击提升16.7%；对骑兵护甲前总伤害26→31，提升19.2%。高级长矛兵打高级骑士、轻骑兵、战象仍为5、4、15次，与普通级完全相同。轻装备和对步兵较弱的直接攻击保留，不能做成小号重装剑士。

### 高级弓箭手：70生命，13攻击，0／6护甲

生命提升16.7%，攻击提升18.2%，远程护甲增加1点。选择70而非机械乘出的72，使同级弓箭手互射仍为10发，骑士击杀它仍为5次。10射程和1.5秒攻击间隔保留，维持远距离齐射职责，不增加穿甲。

### 高级弩手：70生命，11攻击，0／2护甲，3穿甲

生命提升16.7%，攻击提升22.2%；穿甲保持3。高级盾卫和骑士的远甲为8：高级弩手每击伤害为11−(8−3)=6，相对普通弩手打7远甲目标的5点提升20%。若穿甲改为4，每击会变成7，提升40%，所以本级不增加穿甲。仍保留7射程、每秒一发和需要前排保护的特点。

### 高级火枪手：90生命，27攻击，0／1护甲，3穿甲

生命提升20%，攻击提升22.7%，保留2.2秒攻击间隔、0.35秒前摇、7射程、3.6移速。9种同级目标的击杀次数全部与普通级相同，且仍怕骑兵和三管短炮。将26.4／3.6／1.2直接四舍五入会引入不同的门槛，因此这里明确选27攻击、3穿甲、1远甲。

实际高级火枪手打普通盾卫：27−(7−3)=23伤害，7发击杀；高级打高级盾卫：27−(8−3)=22伤害，9发击杀。三发高级火枪命中高级火枪手后剩9生命，第四发阵亡。钢制胸背甲的外观强化主要由生命提升体现，并不意味着必须同步添加近战护甲。

### 高级骑士：145生命，11攻击，2／8护甲，对远程步兵+3、攻城器+13

生命提升20.8%，攻击提升22.2%，远甲增加1。对远程步兵的护甲前总伤害12→14，提升16.7%，不用把附伤强行从3加到4；对70生命高级弓箭手／弩手仍为5次，对90生命高级火枪手仍为7次。对攻城器总伤害20→24，恰好提升20%。6.1移速保持，仍被反骑兵单位约束。

### 高级轻骑兵：105生命，8攻击，1／4护甲，对远程步兵+3

生命提升16.7%，直接攻击提升14.3%是明确的整数例外；对远程步兵总伤害9→11，提升22.2%，远甲3→4补充突袭生存能力。与高级骑士的145生命、11攻击、8远甲形成明显区别。6.8速度和20视野保留，不增加冲锋或击退，也不继承骑士的攻城器附伤。

### 高级战象：435生命，39攻击，2／3护甲

生命提升20.8%，攻击提升21.9%；仍为骑兵、2人口、单体近战、2.4秒间隔、3.2移速。435生命高于机械缩放的432，使27攻击高级火枪手需要17发，与普通火枪手打普通战象相同；长矛兵仍需15次，战象不会获得抗反骑兵能力。两类护甲保持原值，厚实感主要由生命与护具层次呈现，不增添踩踏范围伤害。

## 九、普通→高级的模型设计规范

**以已认可的高级火枪手 v2 为尺度。** 普通版保留原轮廓；高级增加能在正常战场视角看见的护具面积、分层和武器加固，而不只增加近看才看得见的细线。两者身高、体型、武器类别、握持方式与攻击距离一致。皇家版本将来再使用更显著的纹章、冠饰、华丽材料及轮廓变化。

通用要求：每种高级单位至少有一个中距离可识别的主要强化部位，以及两处辅助强化。保持大块阵营色和低多边形材质；新增装甲使用钢灰、深钢、皮革本色。金属本色不能被全身队伍色覆盖，队伍色也不能被装甲全部遮掉。新装饰优先合并进已有活动部件，避免为铆钉、包边新增独立节点与动画通道。

| 单位 | 主要强化，正常视角应可见 | 辅助细节 | 阵营色保留位置 | 需要守住的身份与接触点 |
|---|---|---|---|---|
| 剑士 | 有层次的胸背甲与双层肩甲 | 前臂护具、护膝、盾缘加固、剑柄金属件 | 上臂衣料、腰侧、盾面 | 保留原盾牌尺度，不变成盾卫的大盾；手与盾柄相连 |
| 盾卫 | 大盾加厚包边和中央钢制加强带 | 肩甲叠片、胸甲下沿、护胫、短剑护手 | 大盾主要色块、盾后衣料、腰侧 | 保留眼部开口与盾后手臂连接；不增加盾牌碰撞面积 |
| 长矛兵 | 分段胸甲和有厚度的肩部护具 | 皮革束带、前臂与胫部小护片、矛头套箍 | 上衣、短袖、腰侧 | 头部仍开放、轻装；保留小木盾、露出面部，不套用剑士重盔 |
| 弓箭手 | 分层皮甲与明确的护肩 | 持弓臂护腕、箭袋口包边、弓把加固 | 衣袖、兜帽或帽带、腰布 | 保留长弓轮廓；弓弦、拉弦手与箭的位置对齐 |
| 弩手 | 明确的前胸护板与肩部加固 | 弩臂金属端件、弩托包边、上弦护腕、箭盒 | 袖部、腰侧与头饰色带 | 弩仍短于弓的视觉纵向轮廓；不改装填节拍与箭口位置 |
| 火枪手（外观通过） | 弧形钢胸甲、深钢背甲、两层肩甲 | 长护腕、护膝、宽帽缘与双羽饰、枪管箍和枪托包边 | 袖子、侧衣、衣摆、帽带 | 已完成贴体甲片和背带；枪长、握把、装填手势沿用普通版 |
| 骑士 | 骑手胸肩甲层次、马头与前胸的适度加强 | 鞍具金属件、护膝、马铠边缘 | 鞍毯、骑手衣料与盾面 | 保持重骑兵；不可遮没马腿、眼睛、缰绳，不扩大马身占位 |
| 轻骑兵 | 骑手轻胸甲和小护肩、清楚的鞍具加固 | 开放简帽的窄金属边、护腕、少量皮革扣件 | 帽带、袖子、两侧短鞍毯 | 保留大量裸露马身，不披整套马铠；脚镫避开鞍毯穿模 |
| 战象 | 额甲与胸部护片加固、骑乘座架更结实 | 象牙根部护环、鞍具包边、骑手局部护甲 | 大块侧披布、额饰色条、骑手袖部 | 保留象眼、鼻、耳的活动空间，不让木杆穿头、不铺满金甲 |

高级火枪手 v2 当前为11个刚性分件、5,444三角面，普通版为4,140面；没有增加每帧技能或独立活动分件。这个样品说明“细节足够”需要可见的层次与色块，而不是通过极多细碎零件堆砌。

后续按每批两个模型验收，每个模型分别检查：同机位普通／高级对照；前后左右与红蓝阵营；待机、行走、出手／命中、收势、死亡；图鉴和真实批量渲染战场；近看握持连接、远看队伍识别。特别复查长矛兵面部、象眼／象鼻、骑手靴子与鞍毯等此前出现过的问题。当前批次未获明确通过前，不制作下一批。
