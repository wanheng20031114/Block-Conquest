## 外观与资源

弩手以弧面胸甲、深钢背甲和金属护肩作为主要升级，增加上弦护腕、弩托包边、弩臂端件和箭盒加固。保留开放软帽、脸部、蓝色袖子与下摆，双手握点、弦长变化、箭口位置及装填动作与普通版一致。近看发现肩部衣料会露出甲片顶部，已调整甲片的厚度与位置。

骑士采用分层肩甲、胸背甲、腹部护片和护膝，盾缘改为钢制包边，头盔保留眼部开口和短阵营色羽饰。战马增加两层前胸甲、贴合额头的护板、皮带扣和鞍具金属件，侧披布与盾面保留大块阵营色，马眼与马腿仍清楚可见。

第一轮实机检查发现初版马胸甲局部埋入马身。修正时直接在离线建模中把甲片顶点投影到现有马身表面，并限制甲片宽度处于前胸投影范围内，防止边缘落到后方马腹；增加必要的纵向折面和真实厚度。模型运行时仍直接加载网格，不做投影或生成几何。靴子移至侧披布外侧，马镫随之调整；新增装备合并进原来的活动分件。

## 验证结果

| 检查 | 结果与范围 |
|---|---|
| 本批集成 | 151项通过：数值、分类、图鉴、放置、混选、移动、Shift队列、暂停、坚守、停止、死亡回收、真实战斗 |
| 原生／批量一致性 | 1,982项通过，覆盖现有7个高级模型的65个活动分件，采样变换和箭口偏差均为0 |
| 可视检查 | Godot 4.6.3 Forward+实际渲染44张画面，71项程序检查通过，并逐视角检查主要连接和攻击、行走、死亡姿态 |
| 作者模型隔离检查 | 395项通过：普通弩手与骑士的顶点、面、颜色、分件与转轴不变；高级版保留原动作曲线 |
| 此前单位回归 | 高级长矛兵／弓箭手146项通过；高级火枪手176项通过 |
| 数值报告复算 | 10,000组单位＋1,300组建筑算例；7个实装定义均匹配整数设计，数值表未变化 |

高级弩手对普通骑士每发7伤害，对轻骑兵／战象每发11伤害；弩矢从真实动画出口发射，飞行后扣血。停止前摇不发射、不造成伤害；重复攻击命令无法绕过1秒冷却；对普通盾卫每发只结算一次7伤害。

高级骑士实战对普通弩手造成14伤害，对普通加农炮造成24伤害。高级长矛兵对它造成29伤害，145生命仍需5击，反骑兵关系保持。

接敌回归覆盖高级弩手分别对骑士、轻骑兵、战象，以及高级骑士分别对长矛兵、轻骑兵、弩手；双方移动意图均无后退，实际退步距离均为0，没有近身反向转身。另执行20单位混战，双方均正常造成伤害。

视觉检查覆盖正面、斜侧、左右侧、背面、俯视、红蓝阵营、头像取景、普通／高级同屏、战场正常缩放及死亡。弩手支撑手与弩托接触偏差小于0.025，0.20秒模型弩矢离弦，装填后重新显示。马铠随对应马身和马头部件运动，没有增加独立碰撞面积。
