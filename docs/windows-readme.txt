积木争霸 0.14.0

启动
解压完整 windows 文件夹，双击 积木争霸.exe。EXE 与 PCK 必须来自同一发布包，并留在同一目录。
FONT_LICENSE.txt 为随包标题字体 ZCOOL KuaiLe 的完整许可，请保留。

林海远征：单人肉鸽第一层
从大厅选择“林海远征”，先选战略，再独立选择初始军队。已有检查点时可以继续上次远征。
在森林地图点击相邻节点，先预览再确认进入；每次移动消耗行动力，回走也会消耗。
可以作战、购物、招募、调整编队、处理不期而遇或在营地补给。拥有的军队不限制数量，出战编队受人口上限限制。
前哨站需要消灭全部敌方建筑与部队。行动力在节点退出后耗尽，会进入不可回避的围剿简报，可先整理编队。
围剿中保护中央大本营150秒；士兵全灭仍可继续，大本营被毁则失败。胜利后保存成长并进入层间整备，第二层暂未开放。
首版远征只支持单人；普通单人和多人对战入口继续保留。

存档与暂停远征
新局建立、完整节点退出、围剿胜利，以及地图上确认招募或阵位修改时保存检查点。
节点内部退出或关闭游戏，会恢复最近一个完整检查点；不保存战斗现场。失败后可读取检查点重试。
待进入围剿的状态也会保存，重新启动或读档不会绕过围剿。开始新远征会替换原检查点。
远征存档使用 Godot 的 user://rogue_run.json，存放在本机用户数据目录。

对战与图鉴
普通单人及多人对战支持1v1、2v2、3v3、4v4、2v2v2和八人乱战；房间空席可添加电脑或保留空位。
联机由房主模拟战斗，客户端接收状态；支持断线宽限期内重连，房主不会迁移。
自己的部队为蓝色、队友为黄色、敌人为红色；仅同队共享视野，不能控制盟友单位。
兵种、建筑、模型、动作和当前数值可在大厅的“战争图鉴”查看；生产与招募界面显示本次操作的费用和人口。

界面与操作
大厅、设置和面板采用柔和卡通风格，使用奶油纸卡、浅木与低饱和绿色，配合轻微按钮反馈和纸页转场。
战斗底部HUD保留原有按钮、栏位与布局，仅底板风格化。
左键选择，拖框多选，右键移动或攻击；Shift追加命令。生产和建造快捷键以按钮角标为准。
中键拖动、方向键或屏幕边缘平移；滚轮缩放；空格定位选中对象。
B选择大本营，F2或G选择全部己方战斗单位，句点选择空闲农民。F1查看完整操作说明。
F5打开战场菜单；F11全屏；M静音；F10隐藏界面。远征地图也可通过暂停菜单退出或读档。
设置入口位于大厅和战场菜单，可以调整显示、声音、镜头及热键。远征战斗内不开放采矿、建造或招募。

联机版本
应用发行版本为0.14.0，网络协议为14，网络Build为0.11.0。
联机要求客户端与服务端的网络协议、Build和内容指纹匹配；相同发行版本不代表修改过的兵种或地图仍然兼容。
所有玩家请使用同一个完整发布包，不要混用不同包的EXE和PCK。若提示版本或内容不匹配，请按提示更换对应发布包。

运行与诊断
建议使用独立显卡。游戏采用Forward+ Vulkan渲染；大量单位仍会增加CPU和GPU负担。
遇到异常时，可双击COLLECT_DIAGNOSTICS.cmd，在“文档/积木争霸-诊断”生成本地ZIP。
诊断包包含日志、近期相关Windows错误、显卡和系统信息以及EXE/PCK校验值，不会自动上传。

从源码重新打包：运行tools/build_windows.ps1。脚本生成内容清单、导出、校验包内内容，并将字体许可一起打入ZIP。
直接使用编辑器导出时，先运行python tools/build_content_manifest.py；联机内容修改后还需确保服务端采用匹配的协议与内容。
