积木战争 · Block Conquest

版本 1.3.2 · 住宅扩张平衡

请将整个 ZIP 解压后运行 积木战争.exe，并保留同目录的 积木战争.pck。
新增叠翠台地（1v1）、盘山双关（2v2）、云冠盆地（3v3）。单位可沿土坡登上高地，陡崖不可通行；选图预览可查看高度与上坡方向。
主菜单选择“开始战争”，选择指挥官和地图后开始对局。
联机选择“多人联机”，创建房间或输入六位房间码加入。房主可自由移动席位，并在任意空位添加电脑；每名玩家独立选择指挥官。
全员准备后由房主开始。只显示队友的鼠标，电脑与对手没有共享鼠标。
Q/W/E/R 施放技能，1–4 选择出兵比例，Esc 打开战场菜单，F1 查看完整帮助。联机菜单不会暂停其他玩家的对局；仍在参战的真人可通过菜单或 F3 暂停／继续全局战局。
多人菜单可投降并留下观战。建筑与行军队伍随机转给同侧尚未投降的真人，建筑内驻军立即减少 40%；该侧全部真人投降即判负，电脑不计入。房主投降后仍继续托管计算。
普通玩家主动离房视为投降；短暂断线 10 秒后由电脑暂代，120 秒内可恢复。房主短暂断线全场暂停，30 秒内可恢复。房主主动离开将结束该房间，本版本不迁移房主。
设置独立保存在 Godot app_userdata/积木战争 目录。
