# 英雄界面：参考拆解与实现记录

2026-09-16。以用户提供的两张《逃离鸭科夫》实机截图为主要视觉参考，重做沙盒英雄背包与底部 HUD。此前仅使用炭灰透明底色，缺少参考中的信息组织、物品体积与状态层次，本轮一并修正。

## 参考分析

| 观察 | 在本项目中的对应实现 |
|---|---|
| 战场占据中心，两侧承担背包信息 | 左侧装备和 24 格背包，右侧当前物品详情，中间保留场景；不虚构仓库 |
| 蓝灰半透明承托面、深色标题条、细浅色格线 | 原生圆角 StyleBox、局部轻度背景模糊、顶边高光与外阴影分别承担层次 |
| 物品轮廓清楚，主体与名称分区 | 药剂使用用户指定的 arc-nice 像素原图；火枪使用游戏模型的原生视口预览 |
| 图标、名称、数量、键帽各有固定区域 | 图标等比居中，底部名称条，右上数量胶囊，快捷键置于格子下方 |
| 暖色轮廓只用于当前武器，青色用于操作 | 武器固定暖色选中边；主按钮与物品选中使用浅青色；空格保持安静 |
| 底栏并非一整块大面板 | 生命胶囊、装备武器、五个补给格和背包入口各自独立 |
| 状态环具有实际含义 | 只显示已有加速效果及剩余时间，不引入饥渴、耐力、重量或其他未实现数值 |

## 设计主张（实施前锁定）

**视觉主张：** 冷蓝灰玻璃承托鲜明的积木质感物品，白色数字与细边保证清晰度。将阴影、顶边反光和局部色光用于区分表面和状态，避免整片发光。与参考接近的质感来自多层结构及统一尺度，而不是简单调整透明度。

**内容安排：** 左上展示真实火枪、随身背包与英雄基础属性，下方紧凑排列实际库存；右侧集中展示所选物品的用途、数量、冷却和使用按钮。底栏直接回答生命、当前弹量、补给数量与键位。装备和消耗品信息来自现有运行时数据，保留 24 格、5 个快捷位与现有药剂规则。

**交互主张：** 背包面板短距离淡入；鼠标和键盘焦点以轮廓与亮度回应；药剂使用后的数量、冷却遮罩和时间即时变化。禁止持续抖动、弹跳或无意义光晕呼吸。拖拽仍用原生 Control 接口，整理必须保留物品总量、快捷绑定及共享冷却。

## 原生实现与成本

- 可编辑节点、资源、样式均保存在 `.tscn` / `.tres` 中，离线工具负责重复生成；运行时不拼装界面节点。
- 使用 [StyleBoxFlat](https://docs.godotengine.org/en/4.6/classes/class_styleboxflat.html) 的抗锯齿圆角、边框和阴影。
- 背包显示时由一个 [BackBufferCopy](https://docs.godotengine.org/en/4.6/classes/class_backbuffercopy.html) 取得背景，各面板共享 [屏幕纹理 mipmap](https://docs.godotengine.org/en/4.6/tutorials/shaders/screen-reading_shaders.html) 做轻度模糊。HUD 不执行该拷贝，不添加第二个战场相机。
- 武器缩略图使用独立静态 SubViewport，仅渲染一次；同一纹理供装备、底栏与详情共用。
- 药剂直接复制 arc-nice 中的 32×32 像素素材，格子、快捷栏、拖拽及详情采用最近邻过滤。参考图用于 UI 布局与面板层次，不改变用户指定的药剂美术风格。
- 1600×900 为布局基准，小窗口统一缩放界面，物品贴图始终保持长宽比；不同宽高比保留左右锚点。
