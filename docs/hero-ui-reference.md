# 英雄界面：透明面板参考与应用

2026-09-16，用户要求调查《逃离鸭科夫》的背包与底部栏，并采用带透明感的设计。

参考来自[游戏 Steam 商店](https://store.steampowered.com/app/3167020/Escape_From_Duckov/)的[官方背包截图](https://shared.fastly.steamstatic.com/store_item_assets/steam/apps/3167020/ss_ffb859764420f62c612287f011361749a06b6432.1920x1080.jpg)。已实际查看截图，未复制其图标、美术或布局资源。

观察：灰色半透明物品区域、细亮边方格、较清晰的物品图标与数量；主要面板位于两侧，中心保留场景；底部快捷格独立排列，键位清晰。

视觉主张：用偏暖的炭灰半透明面板、象牙白文字、少量浅金状态色，让森林战场透过界面，同时与积木角色的木材和黄铜细节协调。

内容安排：背包左侧展示 24 格库存，右侧展示当前物品与已装备武器，中央保留战场；底部独立显示五格快捷栏。角色创建仍以真实模型为中心，表情与配色控件采用同一透明主题。

交互主张：原生控件提供悬停和焦点轮廓；拖动物品保持等比预览；使用后由数量和冷却条立即反馈，不加入晃动或弹跳。通过 StyleBoxFlat 的 Alpha 混合实现透明，不新增实时背景模糊或全屏重复渲染。

范围：本轮英雄创建、英雄背包、英雄暂停面板与英雄底部栏。游戏其他模式的界面不共用这份独立主题。
