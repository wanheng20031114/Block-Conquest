# 青蛙隐身、持续虚弱与炮塔遮挡修复

首轮记录：2026-09-28，Godot 4.6.3，Windows / Vulkan Forward+。当前规则更新于 2026-10-01；下方历史检查与图片仍保留当时的状态。

## 当前规则

- **E 隐身**：圈选松手时半径 4.5 米内已经出发的自己部队。完全隐藏实体、轮廓、影子及暴露位置的附带特效，持续到本次行军进入任意建筑。炮塔无法锁定或命中隐身士兵。重复选中已隐身部队不会重复收费。
- **Q 弱化雾气**：雾区半径 3.5 米、持续 3 秒。接触雾气的敌军获得攻击 −30 个百分点的虚弱，出雾及雾散后持续到入城；同类虚弱不叠加，驻军增援依旧按真实人数计算。雾内敌方建筑技能防御 −25 个百分点，只在雾存在时生效，不影响中立或友方建筑，也不因多片雾叠加。
- 雾内所有阵营的士兵都不会被炮塔攻击；未隐身者出雾或雾散后可重新成为炮塔目标。已经出膛的炮弹失去目标后落向最后可见位置，不会在士兵重新出现时恢复追踪。
- 隐身和虚弱跟随真实士兵，兔子劝返会保留；入城消耗本次行军对象，新派部队不继承状态。火攻与熊的法术球仍能击杀隐身或雾内士兵。
- 选人摘要、战斗拖拽提示、悬停说明和电脑施法判断同步更新。AI 会用隐身保护经过敌方炮塔的己军，用雾气时考虑掩护敌军的代价，也为即将抵达的己方或盟友攻城部队降低敌楼防御。费用与冷却保持既有值。

## 2026-10-01 图鉴与电脑检查

攻城雾气 AI 专项 **24 项**、全角色原生图鉴 **434 项**通过。新场景用真实士兵攻占被雾气削防的敌楼，并在循环中交替展示部队虚弱与建筑减防；隐身演示等整队出门后施放，二十名士兵全部消失，再按原路线入城。检查了常规与小窗口布局。AI 覆盖盟友攻势、三秒内可抵达判断、已有雾气不重复削防、保护罩叠算，以及敌方隐藏人口变化不影响选点。

建筑规则 **53 项**、联机恢复 **33 项**、青蛙规则与渲染 **109 项**、持续状态 **65 项**通过。到期边界覆盖士兵抵达和真实火环扫过建筑，长短步长结果一致；雾气计时在本段伤害完成后结算。完整隐身的真实 GPU 检查 **47 项**通过：隐身部队及自己、队友、敌方的联机视角与空场景逐像素一致；技能预览、脚步、尾迹、死亡和召回尘土均不泄露位置，盲放范围技能依旧能命中。旧透明渲染池已移除，相关渲染与地表回归同步适配。远程中继未在本次验证中更新，联网发布仍须同步内容清单。
