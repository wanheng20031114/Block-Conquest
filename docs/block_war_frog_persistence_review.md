# 青蛙隐身、持续虚弱与炮塔遮挡修复

2026-09-28，Godot 4.6.3，Windows / Vulkan Forward+。

## 当前规则

- **E 隐身**：仍圈选松手时半径 4.5 米内已经出发的自己部队。实体和边缘进一步变淡，移除六秒到期，持续到本次行军进入任意建筑。炮塔无法锁定或命中隐身士兵。重复选中已隐身部队不会重复收费。
- **Q 弱化雾气**：雾区半径 3.5 米、持续 3 秒。接触雾气的敌军获得攻击 −20 个百分点的虚弱，出雾及雾散后持续到入城；同类虚弱不叠加，驻军增援依旧按真实人数计算。
- 雾内所有阵营的士兵都不会被炮塔攻击；未隐身者出雾或雾散后可重新成为炮塔目标。已经出膛的炮弹失去目标后落向最后可见位置，不会在士兵重新出现时恢复追踪。
- 隐身和虚弱跟随真实士兵，兔子劝返会保留；入城消耗本次行军对象，新派部队不继承状态。火攻与熊的法术球仍能击杀隐身或雾内士兵。
- 选人摘要、战斗拖拽提示、悬停说明和电脑施法判断同步更新。AI 会用隐身保护经过敌方炮塔的己军，用雾气时也考虑掩护敌军的代价。费用与冷却保持既有值。
