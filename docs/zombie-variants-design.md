# 僵尸变种：八种独立模型与强度设计

2026-09-19。用户已授权八种变种一次制作，数值由本轮确定，不再逐批等待审批。本轮范围是独立模型、原生动画与可加载的原型数值资源；暂不加入正式PVE、招募、沙盒、战争图鉴、MOBA卡牌或电脑招募名单。

## 强度规则与制作范围

- 每种变种只归入一个1—3级强度档位，不为每种制作三个等级版本。
- 级别用于未来PVE选择敌人；数值按各变种单独确定，不再额外乘一遍等级倍率。
- 本轮不设计成本、招募价格、训练时间或金币掉落。继承数据中的默认`cost = 0`仅是空置字段，不代表已开放免费招募。
- 八种变种在本轮一起制作，不再按照旧的两种一批规则暂停。
- 生命、攻击、护甲、穿甲和类别附伤均使用整数；移速、间隔和距离允许小数。
- 阵营、物理类别、伤害通道、职责与PVE等级分别保存，不用怪物身份覆盖步兵分类。
- 普通僵尸保持100生命、10近战攻击、双护甲0，现有模型保持独立原型状态。
- 外观沿用棱角轮廓、横线眼与横线嘴、破旧衣物和简单阵营袖带。

| 强度级别 | 变种 | 定位 |
|---|---|---|
| 1 | 弓箭僵尸、草叉僵尸 | 基础远程压力、基础反骑兵 |
| 2 | 火枪僵尸、弩手僵尸、斧头僵尸、矿工僵尸 | 高单发、穿甲、强攻、反攻城器 |
| 3 | 摇铃僵尸、门板僵尸 | 尸群支援、重型前排 |

等级衡量整体威胁，不要求高等级的每一项属性都更高。摇铃僵尸的威胁来自尸群鼓舞，不能用其5点近战攻击单独衡量。

### 摇铃鼓舞：为未来PVE预留的能力

| 项目 | 数值或规则 |
|---|---|
| 鼓舞半径 | 5 |
| 移速提升 | +20% |
| 持续时间 | 4秒 |
| 施放周期 | 10秒，从施放开始计算 |
| 目标范围 | 自身与半径内存活的友方怪物步兵；不影响敌方或建筑 |
| 多个铃手 | 同类鼓舞不叠加；重复施放只刷新持续时间，不累乘移速 |
| 额外效果 | 无治疗、增伤、护甲提升、恐惧或召唤 |
| 当前实现边界 | 保存能力参数，提供摇铃动作；当前没有实际施加移速增益的运行时系统 |

这项能力不复用维修或治疗组件。原型使用`MonsterDefinition.Ability.RALLY`保存能力类型，`role = SUPPORT`表达职责，生命恢复专用的`support_kind`保持为空。共享单位校验只抽取支援校验方法，怪物定义明确扩展鼓舞的合法配置；已有工程兵和牧师仍执行原先的维修／治疗校验。

### 弓箭僵尸：基础远程压力

定位是躲在普通僵尸后方持续射击。9射程允许其形成后排，但低于现有弓箭手的10；2.8移速、0护甲和80生命给英雄点杀及骑兵切入留下空间。9攻击、1.8秒间隔也低于我方弓箭手的11攻击、1.5秒间隔。它的威胁主要来自数量和前排掩护，单体不能轻易替代训练有素的弓箭手。

行为建议：接近至有效射程后站定射箭，张弓0.45秒后释放箭矢；移动会暂停射击。敌人贴身时继续用弓攻击，保持较慢的出手节奏，不额外增加徒手连击或连续后撤风筝。弹药无需单独消耗。

造型建议：保留普通僵尸的木讷脸，身形略瘦；装备旧木弓、磨损箭袋及少量外露箭杆。弓把、弓弦与持握手明确连接，左上臂袖带清楚可见。使用侧身、僵硬拉弓和松弦动作区分徒手僵尸；面部不随攻击改变表情。

### 火枪僵尸：少量混入的高单发威胁

定位是需要优先处理的远程敌人。24攻击与2穿甲能伤到前排及英雄；100生命和1远程护甲提高其存活能力。以7射程、2.7移速和3秒开火间隔限制持续输出。其对0护甲理论输出为8，低于我方普通火枪手的22/2.2=10，但一次中弹更重。

行为建议：持枪站定，0.65秒的举枪瞄准动作结束时开火。随后明确表现装填；3秒开火间隔已经包含这段装填表现，不另设多发弹匣或额外换弹等待。弹药无限，射击仍为单体，不附带爆炸、击退、暴击或对英雄的隐藏增伤。

造型建议：装备老式木托火枪、火药袋和旧皮革绑带，局部较厚皮护片对应1点远程护甲。枪械轮廓与弓箭变种明显不同，保留露出的绿色皮肤、破衣和阵营袖带。瞄准、后坐和缓慢装填应清楚可读；开火采用已有轻量枪口反馈与短烟迹方案。

## 与现有单位的伤害核对

计算遵循现有`DamageResolver`：

```text
有效护甲 = max(0, 对应通道护甲 - 穿甲)
实际伤害 = max(1, 基础攻击 + 科技攻击 + 生效类别附伤 - 有效护甲)
击杀次数 = ceil(目标满生命 / 实际伤害)
```

下表以当前普通版本单位、未研究科技、满生命、无治疗和其他增益为准。每格为“单次伤害 / 击杀所需命中次数”；命中次数不等于实战胜负，不包含接近、走位、弹道飞行和集火。

| 被攻击目标 | 生命 / 远程护甲 | 弓箭僵尸 | 火枪僵尸 |
|---|---:|---:|---:|
| 剑士 | 110 / 2 | 7 / 16次 | 24 / 5次 |
| 长矛兵 | 75 / 1 | 8 / 10次 | 24 / 4次 |
| 盾卫 | 145 / 7 | 2 / 73次 | 19 / 8次 |
| 弓箭手 | 60 / 5 | 4 / 15次 | 21 / 3次 |
| 弩手 | 60 / 2 | 7 / 9次 | 24 / 3次 |
| 火枪手 | 75 / 1 | 8 / 10次 | 24 / 4次 |
| 轻骑兵 | 90 / 3 | 6 / 15次 | 23 / 4次 |
| 骑士 | 120 / 7 | 2 / 60次 | 19 / 7次 |
| 英雄 | 200 / 3 | 6 / 34次 | 23 / 9次 |

| 我方攻击者 | 对弓箭僵尸：伤害 / 次数 | 对火枪僵尸：伤害 / 次数 |
|---|---:|---:|
| 剑士 | 9 / 9次 | 9 / 12次 |
| 长矛兵 | 6 / 14次 | 6 / 17次 |
| 盾卫 | 6 / 14次 | 6 / 17次 |
| 弓箭手 | 11 / 8次 | 10 / 10次 |
| 弩手 | 9 / 9次 | 9 / 12次 |
| 火枪手 | 22 / 4次 | 22 / 5次 |
| 轻骑兵（含+2附伤） | 9 / 9次 | 9 / 12次 |
| 骑士（含+3附伤） | 12 / 7次 | 12 / 9次 |
| 英雄基础火枪（20+20） | 40 / 2次 | 39 / 3次 |

据此保留三个明确的应对方式：

1. 盾卫和骑士的7远程护甲能有效承受弓箭僵尸；弓箭僵尸不靠增加穿甲去消除这项优势。
2. 火枪僵尸对英雄每发23，对盾卫每发19，需要走位、远程点杀或骑兵切入；其低移速和长装填间隔提供接近机会。
3. 英雄基础火枪消灭两种僵尸分别需要2发和3发，保留英雄主动清理关键远程敌人的作用。

数量敏感性：3只弓箭僵尸一轮全部命中英雄为18伤害，3只火枪僵尸为69。因此未来波次宜先少量混入火枪僵尸，观察齐射压力，再确定投放数量。这是后续实测的关注点，当前没有设定波次或掉落规则。

## 八种变种的强度交叉检查

以下继续使用上面的伤害公式。英雄使用200生命、双护甲3、基础火枪40远程攻击且无穿甲；盾卫使用145生命、近战护甲3／远程护甲7。

| 僵尸攻击者 | 对英雄：伤害 / 次数 | 对盾卫：伤害 / 次数 | 英雄击杀该僵尸所需枪数 |
|---|---:|---:|---:|
| 弓箭僵尸 | 6 / 34次 | 2 / 73次 | 2 |
| 火枪僵尸 | 23 / 9次 | 19 / 8次 | 3 |
| 弩手僵尸 | 12 / 17次 | 8 / 19次 | 3 |
| 草叉僵尸 | 6 / 34次 | 6 / 25次 | 3 |
| 斧头僵尸 | 15 / 14次 | 15 / 10次 | 4 |
| 矿工僵尸 | 14 / 15次 | 14 / 11次 | 4 |
| 摇铃僵尸 | 2 / 100次 | 2 / 73次 | 5 |
| 门板僵尸 | 8 / 25次 | 8 / 19次 | 8 |

- 草叉对120生命、2近战护甲的骑士：`9 + 16 - 2 = 23`，6次命中；对90生命、1近战护甲的轻骑兵：24伤害，4次命中。它承担反骑兵用途，不获得额外的通用穿甲。
- 矿工对180生命、0近战护甲的加农炮：`14 + 12 = 26`，7次命中。其3穿甲不会对0护甲目标再增加伤害。
- 门板面对普通弓箭手11攻击，每箭受到3伤害，需要80箭；面对22攻击、3穿甲的火枪手，每发受到17伤害，需要15发。未来应作为少量重型前排投放，不能把普通弓箭齐射当成唯一解法。
- 三个远程变种受到骑士对远程步兵+3、轻骑兵对远程步兵+2；三管短炮等对所有步兵的附伤也对八种变种生效。摇铃的支援职责不改变它的步兵类别或伤害通道。
- 以上是首轮基础设计，没有进行正式PVE波次、数量或经济平衡验证。模型预览的视觉检查不能替代后续实战平衡测试。
