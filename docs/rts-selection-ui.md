# RTS 选择与英雄指令面板

视觉方向：沿用战场的木质浅色面板、阵营色与真实模型头像，保持紧凑、清楚的指挥界面。

内容安排：单位详情负责当前兵种状态；部队构成负责头像、数量、生命与筛选；指令区负责整队命令及当前单位能力。英雄在 RTS 中使用相同的单位面板，第一人称仍保留快捷栏。

交互方向：子编组以稳定高亮表示当前查看对象；使用既有短淡入和按钮反馈；冷却遮罩随真实计时更新，不因面板刷新重新播放动画。

## 操作约定

- 多选显示按兵种与所属玩家归类的构成，超过八类分页；数量、生命和人口按实际存活选择计算。
- 点击头像查看该子编组；Tab / Shift+Tab 切换。查看不会改变整队的移动或攻击命令。
- Ctrl 点击仅选择该类；Shift 点击从选择中移出该类。
- 单选英雄显示姓名、生命、双护甲、实际武器攻击和弹匣；攻击前进、停止、坚守仍是普通单位命令。
- 英雄五个道具快捷位映射到 RTS 指令槽 Q/W/E/R/T，第六槽 Y 装填；I 打开背包，F5 进入第一人称。绑定后的热键以设置为准。数字键继续用于 RTS 编队。
- 混编时只有当前查看英雄子编组才显示和响应英雄能力；没选中英雄时不显示英雄专属操作。
- 战场、沙盒与肉鸽战斗共用同一构成组件。复用模型预览缓存，不为每名士兵创建视口。

## 实现与验证（2026-09-17）

- `scenes/selection_composition.tscn` / `scripts/selection_composition.gd` 保存八个原生兵种格子并分页。分组按选择顺序排列，英雄优先；生命和数量刷新不会重新排序。点击保存兵种身份再校验，避免单位阵亡后误选相邻格子。
- 沙盒所有单位使用 `scenes/unit_command_panel.tscn`；英雄仅增加能力行、背包和第一人称入口。英雄实时模型头像单独缓存，只有形象改变时渲染一次。
- 普通战场保留原生产队列，多选农民、建筑与士兵时依据当前查看类别展示对应指令。肉鸽多选时显示所选构成，单选或取消选择后恢复远征军名单。
- 第一人称沿用原血条、快捷栏与背包。RTS 不再显示独立英雄浮动栏；背包键帽与当前视角的实际绑定一致。
- 通过真实指针与按键验证点击查看、Ctrl 筛选、Shift 移出、正反向 Tab、数字编队、英雄道具冷却、装填和 F5 切换；能力使用保留其他选中单位的原订单。
- 无头回归：选择面板 124/124、英雄战斗 79/79、背包与输入 66/66、生产队列 488/488、肉鸽界面 168/168、RTS 指令队列 100/100、客户端选择生命周期 48/48。
- 实际 Vulkan 渲染检查沙盒英雄单选、英雄混编、普通战场和肉鸽构成；布局覆盖 1280×720、1600×900，生产与肉鸽面板另覆盖 1920×1080。测试脚本可使用 `--capture-selection` 输出当前截图到被忽略的 `.local/rts-selection/`。
- 更新旧回归脚本以等待真实场景过场结束，并按现有兵营分页找到骑士、按当前剑士造价校验扣费；不修改兵种数值。
