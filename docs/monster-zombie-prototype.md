# 普通僵尸模型原型

2026-09-19。当前只制作怪物阵营的第一种独立模型，等待外观反馈；未加入沙盒、图鉴、卡牌、出兵、AI、生产建筑或任何对局入口。

| 已确认属性 | 值 |
|---|---|
| 生命值 | 100 |
| 攻击力 | 10 |
| 攻击方式 | 徒手、近战 |
| 近战护甲 / 远程护甲 | 0 / 0 |
| 阵营标识 | 左上臂的一圈简单布带 |

模型采用淡绿色皮肤、暗灰旧衣、褐色短裤和裸露手脚。当前造型采用大块平面和直线切角：头部有平整脸面、斜切额头与收窄下巴，躯干上宽下窄，四肢为带少量切角的矩形截面，手掌和脚掌保持棱角。用户明确不喜欢圆形、圆润的体块；通过轮廓收放和斜切面调整比例。保留两条微笑弧线眼、短笑嘴和很小的棱角鼻子；五官线条沿实际头部三角面贴合，避免悬浮或穿入脸部。衣摆和裤脚的少量不规则边缘直接连在衣料表面上。布带使用现有阵营色材质，其他部位不染队伍色，也没有金属护甲、武器或特效。

实际网格共1,288个三角面、8个刚性分件；皮肤、衣料与五官按运动部件合并，共用现有单位材质。保存待机、行走和徒手攻击三种原生动画：待机2.8秒循环、行走1.08秒循环、攻击动作0.82秒，向前挥手的接触姿态位于0.30秒。行走时根据实际腿部顶点校正落地高度；腰部与裤腿有重叠连接，挥手后恢复到待机姿态。

这些时长用于模型展示；移动速度、攻击间隔、价格与产出规则尚未设计。原型数据采用现有UnitDefinition保存已确认属性，未覆盖的字段沿用资源默认值，不代表已确定的玩法平衡。未来启用时再决定怪物阵营规则、移动参数、攻击范围与批量渲染接入。

## 文件与查看方式

- `assets/models/units/zombie.tscn`：可编辑模型、层级、动画、手部接触标记。
- `assets/models/units/zombie/`：8份分件GLB、对应原生ArrayMesh及分件清单。
- `tools/unit_zombie.py`：本单位离线建模与动画作者文件。
- `data/prototypes/monsters/zombie.tres`：独立原型数据；不注册到正式BalanceCatalog。
- `tests/fixtures/zombie_model_study.tscn`：独立检查场景。在Godot中打开后按F6运行，可拖动旋转、滚轮缩放，并用1/2/3切换待机、行走、攻击，用4切换布带颜色。游戏菜单不提供此入口。
- `tests/zombie_model_review.gd`：资源与动作检查、六方向及关键帧实际渲染。

只重建本模型：

```text
python tools/build_units.py zombie
Godot --headless --editor --path . --import --quit
Godot --headless --path . --script res://assets/models/units/bake_native_meshes.gd -- zombie
```

`zombie`是显式选择的构建目标，不进入默认的全量兵种生成。现有UnitVisual仅增加Inspector中的模型名称选项；未改变现有单位的运行逻辑。

## 本轮验证

101项原生资源与动作检查通过：生命/攻击/双护甲、近战分类、未注册到正式名册、网格预算、唯一染色部位、动画轨道、49个行走采样的脚底高度、蹬地和抬脚方向、0.30秒的向前接触姿态、攻击结束归位。当前切角造型以Godot 4.6.3 / Vulkan重新查看六个方向、行走及攻击关键帧和三种布带颜色，检查五官贴合、颈部及手臂连接、衣摆与裤脚、矩形袖带的可见性。

检查截图和短动画仅保留于忽略目录`.local/zombie-review`，不把验证图片提交为游戏素材。本轮没有做实战伤害或联机测试，因为原型尚未进入任何玩法。
