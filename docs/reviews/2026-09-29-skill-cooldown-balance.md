# 新技力机制下的技能冷却审查

历史审计：本文及同名 JSON 保留当时的数值与测量结果。2026-09-30 狐狸「惊慌失措」已调整为 70 技力 / 70 秒，猪猪「特大猪」为 80 技力 / 70 秒；当前费用与冷却见[角色规则](../block_war_commanders.md)和[猪猪规则](../pig_hero.md)。

规则基线：`4eacf7e`。本轮只检查数值、施法条件及收入支出关系，不改游戏费用、冷却或 AI。补充五英雄预算脚本与审查结果；旧能量塔预算脚本遗漏的狐狸已纳入。

## 结论

**高战损叠加能量塔确实可能让技力收入超过技能消耗能力；狐狸以及没有施工机会的后期熊最需要关注。尚无依据整体缩短冷却。**

五组真实双 AI 对局均未观察到“满技力且四项技能同时冷却”，但观察到部分英雄大量满溢，说明目标条件与 AI 出手判断也在限制有效支出。合成压力场景则能明确复现由冷却造成的满溢。两种证据应分别理解，不能把 AI 不施法全归因于 CD，也不能用其未遇到全冷却证明所有强度场景都没问题。

## 现有费用与冷却

四技能独立冷却，施放当刻计时，与持续效果重叠；没有全局冷却。理论长期消耗上限是各技能“费用 / 冷却”的和，假设每次都有合法且值得释放的目标，实际有效支出通常更低。

| 英雄 | Q/W/E/R 费用 | Q/W/E/R 冷却（秒） | 理论最高消耗/秒 |
| --- | --- | --- | ---: |
| 松鼠 | 30 / 30 / 35 / 70 | 35 / 28 / 45 / 70 | 3.706 |
| 兔子 | 20 / 25 / 20 / 65 | 20 / 30 / 26 / 70 | 3.531 |
| 熊 | 25 / 25 / 30 / 70 | 30 / 30 / 35 / 70 | 3.524 |
| 青蛙 | 20 / 30 / 20 / 90 | 20 / 32 / 26 / 100 | 3.607 |
| 狐狸 | 25 / 40 / 60 / 80 | 35 / 50 / 65 / 85 | 3.379 |

满技力 100 不足以同时支付任何英雄的四项技能（总费用 130–205）。因此收入超过长期消耗上限、余额达到 100、四项都在冷却，是三个不同的判断。

后 100 秒的收入可写为：`2 + 能量塔加成 + 每秒合格损兵 × 当前士气系数 + 合格占领奖励/秒`。下表不含占领奖励，给出 0–2 星时持续损兵超过理论消耗上限的门槛：

| 英雄 | 无塔（人/秒） | 1 塔（人/秒） | 2 塔（人/秒） |
| --- | ---: | ---: | ---: |
| 松鼠 | 8.53 | 6.03 | 4.78 |
| 兔子 | 7.66 | 5.16 | 3.91 |
| 熊 | 7.62 | 5.12 | 3.87 |
| 青蛙 | 8.03 | 5.53 | 4.28 |
| 狐狸 | 6.89 | 4.39 | 3.14 |

3 至不足 5 星的门槛是此表的 4/3，5 星是两倍；这表只表示收入门槛，不假设实际损兵率与士气独立。前 100 秒基础恢复少 1，低士气门槛增加 5 人/秒。每 20 秒一次能量塔来源的合格敌方占领，平均另加 0.5/秒，使低士气门槛再下降 2.5 人/秒；中立占领不发这项 +10 奖励。

例如百秒后 2 塔、低士气、每秒损兵 5 人，收入为 `2 + 0.75 + 5×0.2 = 3.75/秒`，超过所有英雄的理论消耗上限。此强度必须持续才适合用平均公式；短时间集中伤亡也可能因 100 上限而直接溢出。

## 不能只看四技能合计

- 熊 Q 需要正在进行的付费施工。没有施工时 W/E/R 上限只有 **2.690/秒**；百秒后 2 塔自然回复为 2.75，即使没有战损也高于这一上限。1 塔时，低士气持续每秒约 0.95 人战损即可超过。
- 狐狸 W 在自己满 5 星或敌人没有士气时没有有效目标，Q/E/R 上限降至 **2.579/秒**。1 塔、自己 5 星时，每秒约 0.79 人实际战损即可超过；若因为对方无士气且自己低士气，只需约 0.39 人/秒。
- 狐狸 R 还要求目标阵营另有逃亡目的地。W 与 R 都不可用时，Q/E 上限只有 **1.637/秒**，低于百秒后的自然回复；E 本身还要遇到敌方行军。缩短冷却不能制造这些缺失的目标。
- 为关键时刻保留大招也会降低当下支出，这是合理选择。不能把保留技能造成的满溢全部算作系统故障。

## 验证方法与结果

### 合成压力预算

运行 `python tools/audit_skill_cooldown_balance.py --output .local/cooldown-review/synthetic-budgets.json`。覆盖 180 个稳定收入场景、5 个脉冲伤亡场景、9 个技能条件受限场景。每场比较全部固定施法优先级，并检查技力收支守恒；另以四个相同费用/冷却的技能核对闭式结果。

每场从百秒后的满技力及全技能就绪开始，观察 300 秒；可用技能始终假设有合法目标，一旦可付费且冷却结束便施放。结果取固定优先级中溢出最少者，不声称是全局最优操作。固定士气、损兵率均是压力输入，不是实战统计。

| 场景 | 狐狸 300 秒技力溢出 | 满技力等待秒数 |
| --- | ---: | ---: |
| 1 塔、低士气、每秒损兵 2 人（总收入 2.9） | 0 | 0 |
| 1 塔、低士气、每秒损兵 5 人（总收入 3.5） | 45 | 12.86 |
| 2 塔、低士气、每秒损兵 5 人（总收入 3.75） | 106.25 | 28.33 |
| 1 塔、低士气、每秒损兵 10 人（总收入 4.5） | 290 | 64.44 |

上述存在满能等待的全技能有效场景中，满技力等待时全部技能确实都在冷却。300 秒里满能等待 12.86–64.44 秒，与“整局完全无法施法”不同；这提示较强交战下可能出现可感知的技能等待，需要真人验证。收入 3.75 时其余英雄的最少溢出分别是松鼠 17.5、兔子 40、熊 47.5、青蛙 20，狐狸在此压力下更明显。

### 真实规则双 AI 探针

使用 Godot 4.7.2、裂谷交汇地图、固定种子 294721，五组各让双方使用同一种英雄，双方都按现有 AI 规划，最多模拟 300 秒。继承原战斗脚本仅记录真实自然/塔/战损/占领收入、付费及溢出，没有注入人口或强制施法。按不超过 0.05 秒的模拟子步采样满能与冷却状态；两侧账户收支守恒误差均低于 1e-6。

| 英雄 | 实际观察对局时长 | 百秒后双方满能时间 | 满能且四技能全冷却 |
| --- | ---: | --- | --- |
| 松鼠 | 299.08 秒，正常结束 | 11.00 / 4.70 秒 | 0 / 0 秒 |
| 兔子 | 300 秒，上限停止 | 0 / 0 秒 | 0 / 0 秒 |
| 熊 | 277.95 秒，正常结束 | 83.95 / 63.15 秒 | 0 / 0 秒 |
| 青蛙 | 300 秒，上限停止 | 28.75 / 49.83 秒 | 0 / 0 秒 |
| 狐狸 | 300 秒，上限停止 | 6.10 / 28.20 秒 | 0 / 0 秒 |

前 100 秒十个账户均未满溢。后期平均原始收入为 2.511–2.961/秒，已包含战损与实际建塔；每个满能时刻都至少有一技能 CD 就绪。**就绪不保证有目标或值得释放**，尤其不能用熊 Q 的就绪来证明其他防御技能冷却足够短。熊的满能时间明显偏多，应优先检查有效施法场景与 AI 触发判断。该小样本不覆盖全部地图、多人配合、真人操作或高强度供兵，不能据此推导胜率。

详细原始计账及探针在 `.local/cooldown-review/`；本次实测摘要、收入门槛、压力场景与候选数值对照另保存为 `docs/reviews/2026-09-29-skill-cooldown-balance.json`。能量塔预算补齐狐狸后，125 个基础资源场景均通过守恒核对。

## 调整建议

1. 保留大招冷却。特别是青蛙 R 同时移除 80% 驻军、降级并打断施工，100 秒承担效果强度约束；不能因为自然恢复 90 点只需 45 秒，就将 CD 等同于回满费用所需时间。
2. 兔子暂保留 20/30/26/70。冲刺持续 8 秒且攻击翻倍，召回还能强制敌军折返，进一步提频需要完整战斗收益验证。松鼠和青蛙小技能目前也缺少必须下调的证据。
3. 狐狸可优先试验 Q **35→30 秒**，保持 25 费和单次最多 30 人的伤害上限。它是目标最普遍的小技能；W/E/R 先保留 50/65/85，避免偷星、无人数上限招降和 80% 逃散一起提频。此项是候选，不是本轮已改的数值，也不能消除目标缺失造成的全部满溢。
4. 熊先处理有效目标/AI 出手机会；若真人交战中仍频繁卡技能，再试 W **30→25 秒**。其 4 秒减速覆盖率从约 13% 提升到 16%；E35、R70先保留。单纯降低工具箱冷却无法解决后期没有施工的问题。
5. 以“交战中有合适目标、技力足够、却因冷却错失使用”的时间和频次作为主要判断指标，并记录满溢率、战损收入、技能实际收益。允许少量满溢作为资源上限与防连发约束，不以把每一点技力都花掉为平衡目标。
