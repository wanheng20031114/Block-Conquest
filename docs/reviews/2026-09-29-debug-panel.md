# F4 战场数据面板验证

移除头像下方的常驻属性文字及右下角快捷操作提示，新增原生 `debug` 输入映射（物理 F4）和默认隐藏的战场数据面板。设置页和帮助页同步显示快捷键。

## 数据与输入

- 常驻攻防、移速、士气和铁匠铺来源均读取当前玩家的真实模拟数据；临时技能与所选建筑防御另列。
- 总兵力为建筑驻军加已出门的行军人数。待出队列仍属于驻军，不重复累计。
- 所选敌方建筑遵守现有人口可见规则，不暴露隐藏驻军、可派或待出人数。
- F4 开关不暂停对局，打开时取消未完成的派兵、技能和中键镜头拖动，不扣技力；面板外仍可操作战场。
- 帮助、设置和联机确认层优先处理输入；Esc 从上层依次关闭。帮助层使用原生 `top_level` 隔离键盘焦点，避免选中被遮挡的面板按钮。
- 面板采用原生 PanelContainer、ScrollContainer 和 Timer；隐藏时停止刷新计时器。
