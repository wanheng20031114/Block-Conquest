# 士气倍率与铁匠铺移速修正

士气现有规则已符合确认表：累计门槛为0／500／1000／2000／4000／8000分；0–5级防御倍率100%／120%／140%／160%／180%／200%，攻击倍率100%／105%／110%／115%／120%／125%，移速倍率100%／110%／120%／130%／140%／150%。未填满的星不提前提供加成。

移除铁匠铺的移速规则与所有调用，保留原攻防加成。常驻行军速度只取当前完整士气等级，再与技能加减速相乘；铁匠铺数量、停工、恢复和改建不直接影响行军速度。失去建筑若同时扣除士气并跌破星级门槛，仍按新星级正常降速。

同步更新HUD来源说明、原生帮助、百科、兔子封条说明及规则文档。电脑封条评估不再计算不存在的移速收益。联机副本移除铁匠铺恢复的速度时间轴，铁匠铺单独变化仅同步建筑事实；士气变化继续携带权威位置，技能时限与路线区间仍由统一行军算法处理。
