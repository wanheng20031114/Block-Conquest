# 入门教程

教程分为 **两章核心教学** 与 **九项进阶练习**。从未玩过教程的玩家点击主菜单入口后，直接进入核心第一章；教程场景实际就绪时才记录“已开始”。之后再次进入才显示章节页，可以继续学习或单独重练。旧版教程完成记录也视为已经玩过，保留原记录，但不会把旧课自动算作新核心章节完成。

新游戏主菜单仍会暗化并框出「入门教程」，提示可用「稍后再说」或 Esc 关闭。首次推荐状态保存在 `user://onboarding.cfg`；教程访问与完成状态保存在 `user://tutorial_progress.cfg`，两者独立。

## 核心第一章：基础指挥

顺序为操作在先、界面说明在后，每个操作都由玩家实际完成。

| 步骤 | 玩家看到的引导与完成条件 |
| --- | --- |
| 缩放 | 在空白处滚动滚轮，视野实际拉近或拉远 |
| 移动 | 中键拖动并松开，或方向键实际移动视野 |
| 归属与驻军 | 回到清晰视野，认识金旗、灰旗及驻军数字 |
| 调兵 | 从己方住宅拖向中立住宅，真实行军并占领 |
| 顶部战况 | 解释总兵力、兵力占比与计时 |
| 士气 | 指出双方星星，简述攻防与移速收益 |
| 出兵比例 | 高亮左侧比例；必须亲手换成另一个比例，重复选择原比例不完成 |
| 技能与技力 | 解释四个技能、共用技力和独立冷却 |
| 建筑面板 | 指出升级、改建入口，结束第一章 |

章末提供「继续：建筑与技能」与「先到这里」，由玩家选择。继续才加载第二章；结束则回到章节页，不强制接课。

## 核心第二章：建筑与技能

整章使用同一张四建筑练习地图：后方住宅、改建工坊、中立据点和敌方据点。中立据点攻下后，成为后续技能练习中的己方前哨。

教程脚本按步骤配给人口与技力、安排敌军，不需要玩家等待自然产兵。三次改建都由玩家点击正式改建按钮，费用、建筑模型切换和完成信号使用原生流程；仅本章将施工缩短至 **1.2 秒**。正常对局仍为 **10 秒**。

| 连续步骤 | 设计与真实完成条件 |
| --- | --- |
| 改建炮塔 | 选中工坊，玩家点击炮塔图标；建成后说明用途与数据 |
| 炮塔防守 | 8 名敌兵进攻；观察至少两次炮击，清除敌军并守住炮塔 |
| 改建铁匠铺 | 玩家点击铁匠铺图标；建成后展示全军攻击 +30%、防御 +15%、不产兵 |
| 20 人攻 24 人 | 后方备好 40 人，固定 50% 派出恰好 20 人，攻占 24 人中立一级住宅；没有替换伤害结算 |
| 改建能量塔 | 玩家亲手将铁匠铺改成能量塔；说明基础恢复 1 点/秒、首塔额外 0.5 点/秒、不产兵 |
| 短看技力增长 | 从 25 技力开始，观察实际增长 3 点，随即继续 |
| 征召防守 | 前哨仅 4 人，补足施法技力；玩家施放征召后，22 名敌兵进攻。实际补兵与交战结束，前哨仍归玩家 |
| 出兵反击 | 前哨补到 40 人，玩家派出 20 人反击；队伍出门即暂停，接上战鼓操作 |
| 战鼓加速 | 玩家把技能拖向己方队伍；必须实际加速并抵达敌点。敌方预留 65 人，受攻击后仍保留据点 |
| 护盾挡敌 | 前哨补到 19 人，24 名敌军反扑。玩家在冻结的战况下瞄准施放，实际承受带盾伤害并守住 |
| 火焰清场 | 前哨补到 6 人，40 名敌军形成密集队列。玩家施放冲击，真实烧毁整支部队并守住前哨，完成核心教学 |

四个技能各自开始前补足 100 技力；敌军先后出现由教学步骤驱动，不启用自由决策 AI。战鼓或护盾的有效结果出现后立即接下一步，剩余持续时间按正常规则延续，不为等待光圈消散额外停留。

火焰落点偏移导致漏兵时，战况冻结并显示「重试这一步」。只重置当前敌军波次、前哨和本次技能资源，不重打整章，也不把失守或漏兵计为成功。右键取消、失焦取消、错误目标均不消耗教学机会。

## 进阶教学

进阶保留九个可独立重玩的专题：住宅升级、士气与战果、炮塔防线、铁匠铺加成、技力恢复、征召军令、疾行战鼓、防护罩、天降冲击。核心掌握之后可以按需选择，无强制解锁链。

## 讲解与实现边界

- `tutorial_catalog.gd` 保存核心顺序、简短文案、数据表与进阶课程内容。建筑数据直接引用正式规则常量。
- `tutorial_battle.gd` 处理教学暂停、原生操作许可、目标判据、章节结束和本步重试。讲解期间生产、行军、技能与战斗冻结，鼠标示范继续播放。
- `tutorial_core_scenario.gd` 只安排核心第二章的补给、敌军波次和施工速度。没有修改 `scripts/block_war/` 正常规则。
- `scenes/tutorial/maps/` 保存两张核心地图与九张进阶地图。节点、建筑、装饰与道路在 `.tscn` 中编辑，不在游戏脚本中临时创建教学节点。
- `tutorial_overlay.tscn` 使用原生 CanvasLayer、Container、Button、Label 与动画。正文下的数据表为固定四行 GridContainer，随屏幕密度调整，换步骤时清空。数据表和带鼠标示范的操作讲解使用较窄说明列，为高亮目标与完整示范路径留出空间；重看讲解沿用同一布局。
- `tutorial_progress.gd` 使用 ConfigFile，`started` 与 `completed_lessons` 共同保存；记录读写错误会保留原数据并返回错误。章节完成不会改动普通对局、指挥官或联机选择。

暂停菜单继续支持 Esc/F3；恢复时保持原来的讲解或练习状态。重看讲解保留已经累计的结果，重复打开不会重复生成敌军。首次进入和原生场景转场分别管理，未成功加载不会提前记录访问。

原生能力参考：[PackedScene](https://docs.godotengine.org/en/4.6/classes/class_packedscene.html)、[Control](https://docs.godotengine.org/en/4.6/classes/class_control.html)、[GridContainer](https://docs.godotengine.org/en/4.6/classes/class_gridcontainer.html)、[ConfigFile](https://docs.godotengine.org/en/4.6/classes/class_configfile.html)。
