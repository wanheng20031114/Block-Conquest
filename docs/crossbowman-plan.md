# 弩手制作与分类整理 · 2026-09-14

当前单位：弩手；版本：v1；待修改：等待用户外观意见；验收：建模、试装、分类与图鉴筛选已完成，等待验收。详见[交付与验证记录](../report/crossbowman-2026-09-14.md)。

弩手价格75、生命60、近战护甲0、远程护甲2，9远程攻击、固定穿甲3，间隔1秒、前摇0.20秒、射程7、移速3.6、视野14、人口1；兵营训练9秒。穿甲在防御科技后计算，剩余护甲最低0，伤害最低1；攻击科技只提高基础攻击。对建筑同样穿甲，没有建筑附伤。

分类分为独立的攻击方式（近战/远程）、物理类别（步兵/骑兵/攻城器/建筑）与单位职责（作战/支援/建设）。远程步兵由步兵类别和远程攻击方式共同确定。工程兵和牧师为支援；农民为建设，仍属步兵，使用农民人数上限。支援单位使用军事人口。骑士+3、轻骑兵+2改为针对全部远程步兵。用户已确认三管短炮和防御塔的步兵附伤扩展至所有步兵，因此也覆盖弓箭手、弩手和建设职责的农民。

图鉴视觉方向：保留纸张、墨绿文字与黄铜细节，以真实模型为视觉中心。左侧单位导航加入三项紧凑筛选；右侧标题下显示来自同一份战斗数据的标签；筛选结果支持组合与清除。沿用原生按钮反馈、页面进入动画及可旋转模型，避免增加干扰阅读的装饰动效。

建模采用现有低多边形分件网格，开放式软帽、阵营色衣料、轻皮甲、横置短弩与腰侧弩矢袋。双手握持、扳机、弓弦、装填及发射口在原生场景中制作；仅离线导出弩手。依次检查多角度静态、连续攻击/装填、真实战场批量渲染。
