# 林海远征 · 单人肉鸽第一层

在大厅选择 **林海远征**。先选战略，再选初始部队；已有存档时可以继续上次远征。新局会替换当前检查点。

## 探索与补给

点击模型节点预览，确认后移动。只能前往直接相邻的节点，每次移动消耗1行动力，回走也会消耗。中键拖动地图，滚轮缩放。

作战、紧急作战、商店、不期而遇和营地均为一次性内容；完成后仍可通过，但不会刷新奖励或商品。商店离开后不可再次购物。

右上角依次为金币、吐司面包、行动力。金币用于购物，面包用于招募；收藏品位于地图下方，点击查看效果，同名收藏品的效果相加。

初始等级1、人口上限20、金币20、面包3、行动力12。每次升级获得1面包和5人口上限。等级只在本局内成长。

## 军队与招募

编队页左侧分为出战军队与待命区，相同兵种合并显示数量。单击一行选择该兵种，Shift/Ctrl单击增减选择；双击转移1名，Shift双击转移该兵种全部单位。右侧按钮可以一次转移当前选择。

中央模型阵地支持单选、框选、Shift/Ctrl追加选择、拖动与右键整组移动；Q/E绕队伍中心旋转，右侧也可输入坐标与朝向。双击阵地上的模型可直接将该单位移入待命区。按Esc先取消正在进行的拖动，再按可返回地图。前哨站与围剿分别保存阵位，围剿中央大本营不能被单位占用。超出人口、越界或重叠的操作会提示原因并保持原阵形。

待命区不限制人数，只有出战单位计入人口。重型火炮占5人口，20人口可以部署4门。战场内的死亡、伤势和位置不会改变名册及初始阵形，下一场重新满血部署；作战失败仍会结束本局。

招募券不能留存：开局、战后、商店购买或事件获得时立即使用。第一轮三张卡牌选择兵种，第二轮三张卡牌选择1、2、3批，明确显示人数与面包总价；买不起的卡牌呈灰色并显示还差多少面包。第二轮可返回重选兵种，候选不刷新；确认后一次性扣除面包，新单位加入待命区。

不想招募时可以弃置，界面会再次确认。商店买券消耗的金币不因弃置退还。Esc只打开暂停菜单，不能把招募券留到以后。旧存档中已有的券会保留原候选，并依次要求处理。

## 作战

前哨站：从西侧向东推进，消灭5座箭塔、3座兵营及全部敌军。驻守部队会反击、支援受攻击的据点，搜索队会寻找我军。存活兵营会继续生产援军，摧毁兵营可以切断增援；目标面板显示当前敌军与累计出现数量。紧急版本使用同一地图，初始敌军更多，增援也享受强化。

行动力在节点退出后归零，会自动出现不可回避的围剿简报。可以调整军队或退出续玩，不能绕过围剿继续探索。

围剿：保护中央大本营150秒。敌军从四边分7波增援，场上同时存活上限24。大本营被毁立即失败；我方士兵全灭仍可继续坚守。胜利后恢复行动力并保存到层间整备页，第二层暂未开放。

战斗保留原有RTS选择、框选、右键指令、A攻击前进、S停止、H坚守、数字编组与镜头操作。F5/Esc打开暂停，开场可跳过。战场内不开放经济、建造和招募。

前哨站胜利后显示战利品页，领取金币、面包、经验和招募券；升级额外奖励同时列出。领取后自动进入招募，紧急作战还需选择收藏品，全部处理后才离开节点并检查行动力。围剿胜利显示恢复行动力与层间整备，不发普通节点奖励。

底部主面板可查看小地图、选中单位的模型/生命/属性、部队头像和编组人数。头像列表可翻页；Ctrl+数字建立编组，数字键或对应编组按钮选择，Shift用于追加。全军按钮选择当前仍存活的出战部队。待命名册和初始阵位仍在战斗外的编队页编辑。

## 暂停远征与读档

新局建立、完整节点退出、围剿胜利确认，以及地图上确认阵位时保存。开局和旧存档待处理招募的兵种选择、确认与弃置也会更新当前检查点，重启仍恢复同一轮选择。活动节点内部（包括商店招募、战后领取和招募）不覆盖检查点；中途关闭游戏或返回大厅，会从最近完整节点恢复。

失败后保留最近检查点，可选择读取重试。围剿待触发状态也被保存，读档不会绕过它。

存档位于 Godot 的 `user://rogue_run.json`，使用临时写入、内容校验与替换。测试使用独立文件，不修改玩家存档。

平衡数据集中在 `data/rogue/first_floor.tres` 与 `data/rogue/battles/`；新场景均可在Godot编辑器直接打开调整。
