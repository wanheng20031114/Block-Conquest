# 林海远征 · 单人肉鸽第一层

在大厅选择 **林海远征**。先选战略，再选初始部队；已有存档时可以继续上次远征。新局会替换当前检查点。

## 探索与补给

点击模型节点预览，确认后移动。只能前往直接相邻的节点，每次移动消耗1行动力，回走也会消耗。中键拖动地图，滚轮缩放。

作战、紧急作战、商店、不期而遇和营地均为一次性内容；完成后仍可通过，但不会刷新奖励或商品。商店离开后不可再次购物。

右上角依次为金币、吐司面包、行动力。金币用于购物，面包用于招募；收藏品位于地图下方，点击查看效果，同名收藏品的效果相加。

初始等级1、人口上限20、金币20、面包3、行动力12。每次升级获得1面包和5人口上限。等级只在本局内成长。

## 军队与招募

编队页左侧为完整名册，中央是真实模型布阵区。拖动单位或右键指定位置，Q/E旋转；右侧也可以输入坐标与朝向。前哨站与围剿分别保存阵位，围剿中央大本营不能被单位占用。

待命区不限制人数，只有出战单位计入人口。重型火炮占5人口，20人口可以部署4门。战场内的死亡、伤势和位置不会改变名册及初始阵形，下一场重新满血部署；作战失败仍会结束本局。

每张招募券有三个固定兵种候选。选择一种，再选择1～3批，界面显示面包总价和获得数量。确认时消耗一张券；取消不消耗，不重抽候选。新单位进入待命区，需要手动加入编队。

## 作战

前哨站：从西侧向东推进，消灭5座箭塔、3座兵营及全部守军。驻守部队保卫据点，搜索队会接近我军。紧急版本使用同一地图，敌军更多且属性更强。

行动力在节点退出后归零，会自动出现不可回避的围剿简报。可以调整军队或退出续玩，不能绕过围剿继续探索。

围剿：保护中央大本营150秒。敌军从四边分7波增援，场上同时存活上限24。大本营被毁立即失败；我方士兵全灭仍可继续坚守。胜利后恢复行动力并保存到层间整备页，第二层暂未开放。

战斗保留原有RTS选择、框选、右键指令、A攻击前进、S停止、H坚守、数字编组与镜头操作。F5/Esc打开暂停，开场可跳过。战场内不开放经济、建造和招募。

## 暂停远征与读档

新局建立、完整节点退出、围剿胜利，以及地图上确认招募或阵位时保存。活动节点内部不覆盖检查点；中途关闭游戏或返回大厅，会从最近完整节点恢复。

失败后保留最近检查点，可选择读取重试。围剿待触发状态也被保存，读档不会绕过它。

存档位于 Godot 的 `user://rogue_run.json`，使用临时写入、内容校验与替换。测试使用独立文件，不修改玩家存档。

平衡数据集中在 `data/rogue/first_floor.tres` 与 `data/rogue/battles/`；新场景均可在Godot编辑器直接打开调整。
