# 出兵比例选择器：四套交互提案

状态：供选型的交互原型，尚未替换游戏 HUD。使用当前林湖地图实拍作为背景；百分比、键帽与动效均为可操作界面。

`designs.html` 是用于 Codex 对话预览的自包含片段，使用预览环境提供的方案切换器。截图已内嵌，无需请求地图资源。片段不足 1 MB，正式游戏不会加载此文件。

## 四个方向

| 方案 | 视觉与信息结构 | 切换动作 | 取舍 |
| --- | --- | --- | --- |
| A 积木叠片 | 四个独立纸色块，侧面小榫头呼应积木；键帽在左，比例右对齐 | 180 ms 内选中块前移 8 px，侧缘和键帽加深 | 品牌感较直接；整体仍是纵向排列，学习成本小 |
| B 游标滑轨 | 单块深绿底板、四级标尺、固定数字与右侧键帽 | 220 ms 内游标沿标尺滑行，标尺填充同步变化 | 读数稳定，切换方向明确；连续底板遮挡面积较大 |
| C 阶梯旗签 | 凹尾旗签；四种长度表达比例等级，文字继续给出精确值 | 160 ms 内选中旗签探出 7 px | 更有指挥旗的意味；不等宽轮廓比 A、B 更活跃 |
| D 四格指令盘 | 上排 75/100，下排 25/50；四格内各自显示键帽 | 200 ms 内选块在四格间平移 | 显著减少纵向占用，但增加横向占用；需要适应两行布局 |

建议先比较 A 的积木气质与 B 的读数稳定性。若首要目标是压缩高度，优先 D；若希望保留军令旗的视觉语言，优先 C。C 的宽度只表达等级，不是线性百分比尺。

## 共同交互约定

- 主键盘与小键盘均保留 `1 → 25%`、`2 → 50%`、`3 → 75%`、`4 → 100%`。按键提示始终可见，鼠标可以直接点击整个选项。
- 四套预览共享比例，切换方案时可以比较同一个选中状态。方案切换不会启动动画演示。
- 比例立即生效，动画跟随状态；快速再次选择会打断当前过渡，不排队等待。
- 数字与键帽提供精确读数，底色、位移或游标提供选中位置，状态识别不只依赖颜色。
- B 在整个滑行区间保持浅字配深底；D 保持深字配浅底，避免高亮尚未抵达时文字暂时失去对比度。
- 日常无循环闪烁、粒子或呼吸动画。“播放切换”只演示一次 `25 → 50 → 75 → 100 → 75 → 50`，随后停止；点击、按键、切换到另一方案、页面离开均可终止演示。
- 支持系统减少动态效果设置；预览设计控件可调整 120–300 ms 时长、阴影背景和减少动态效果。设计控件由预览环境提供。
- 上下说明栏、方案切换器和演示按钮仅属于提案展示，不是正式 HUD 的一部分。

## 验证记录

2026-09-27，通过实际浏览器交互验证：

- 四套方案各 4 个鼠标选项、主键盘 4 键、小键盘 4 键，共 48 项状态检查通过。
- 动画演示可以被数字键立即中断；完整演示结束后返回 50%，停止计时。
- 四套方案在 320 px 和 736 px 内容宽度下检查；320 px 下无横向溢出，按钮高度分别为 47 / 52 / 45 / 64 px。
- 检查 10 组正文、键帽和移动高亮背景的配色，最低对比度为 4.92:1；B 的移动高亮与普通读数为 5.70:1。
- 浏览器无原型脚本错误。此阶段没有修改、导出或启动 Godot 游戏，也不代表已经完成引擎内集成验证。

最终方案确认后，再将选中的结构写入原生 `.tscn`，沿用 `ButtonGroup`、现有百分比信号与数字键逻辑，使用可中断的原生 Tween 实现对应动效。
