## 入口与操作

自由沙盘 →「我的英雄」→ 姓名、队伍、配色、表情和装饰 → 创建英雄。

| 操作 | 第一人称 | RTS |
|---|---|---|
| F5 | 返回 RTS | 操控拥有的英雄；无英雄时保留原暂停行为 |
| 移动 | WASD | 选中英雄后右键地面 |
| 攻击 | 按住左键自由瞄准，可以打空 | 右键敌人自动攻击 |
| 换弹 | R | 英雄栏的换弹按钮 |
| 跳跃 | Space | Space 保留聚焦功能 |
| 背包 | I | I 或背包按钮 |
| 药剂 | 1–5 | Alt+1–5 或点击快捷格 |
| 暂停、设置 | Esc 菜单 | 原沙盘按钮 |

开启交战后英雄才移动或开火。F5 不改变暂停状态。打开背包、角色编辑或第一人称菜单时暂停模拟；关闭后恢复之前状态。输入姓名或操作模态面板时，数字键不触发药剂。

形象保存到 `user://hero_profile.cfg`；首版不保存沙盒战场、弹药或本局库存。阵亡返回 RTS，可从「我的英雄」免费重新创建。编辑已有英雄的外观不会回满血、补弹或清除冷却。

## 模型与外观

- 身体圆周 48 段，顶部、底部各有 8 段圆弧，保持长胶囊轮廓。
- 脸面用 12 圈 × 64 段曲面贴合身体，眼和嘴也由同一表面定位。旧版大三角扇切入身体的问题已修复。
- 默认可见模型与火枪共 7,430 个三角面；包含全部备选表情和饰品的资源共 11,972 面。未选择的部件隐藏。
- 旅行宽檐帽的帽冠、帽带和帽檐与胶囊头顶同轴，帽冠覆盖头顶轮廓并留有余量，帽带沿帽冠曲面贴合。只重导出 `TrailHat` 分件；已用实际游戏预览检查正面、左右侧面、背面及搭配羽毛的效果，修复前侧头顶穿出帽子的情况。
- 六种表情：默认微笑、开心、眨眼、专注、惊讶、悠闲。默认无眼睛高光球、眉毛和鼻子。
- 帽子：无帽、默认皮革小帽、贝雷帽、旅行宽檐帽。
- 可组合装饰：小背包、圆鼻子、圆框眼镜、阵营围巾、小胡子、帽边羽饰。
- 支持阵营衣色 / 自选衣色、脸色、靴色；自选衣色仍保留固定阵营布章。一键还原默认外观时保留姓名和队伍。
- 身体、脸、表情、饰品和火枪均为独立网格与原生场景。持枪部分以胸部为转轴，待机横持、开火朝前、装填抬枪，双手随枪保持握持。

## 透明界面与素材

视觉、内容和交互设计记录见 `docs/hero-ui-reference.md`。已实际查看 Duckov 官方截图；只参考设计思路，未复制其图标、美术或布局资源。

英雄使用独立的炭灰半透明主题、暖白文字与浅金交互边线。背包左侧是 6×4 库存，右侧是物品详情与已装备火枪，中心保留战场；五格快捷栏独立放在底部。

透明通过原生 `StyleBoxFlat` Alpha 混合实现，不新增全屏实时模糊。模型预览和第一人称武器使用独立 `SubViewport`，按需停绘；背包打开后隐藏武器、准星和重复 RTS 控件。图标均等比例显示。

药剂图标经用户指定从 `Documents/arc-nice/resources/texture/consumables/` 复制，原项目只读。背包图标由生图工具输出原生透明 PNG，Godot 导入限制为 256 像素。来源见 `assets/ui/hero/CREDITS.md`。

## 背包试装值，尚未正式验收

24 格库存、5 个快捷位、每格最多 5 瓶；初始恢复药剂 3 瓶、加速药剂 2 瓶。这些是可调整的试装默认值，不视为用户明确确认的正式平衡数值。

| 道具 | 试装效果 | 冷却 |
|---|---|---|
| 恢复药剂 | 立即恢复 60，钳制到最大生命；满血不扣物品 | 10 秒 |
| 加速药剂 | 速度 +20%，持续 10 秒；4.2 → 5.04；不叠加 | 15 秒 |

快捷格引用同一库存；移动、合并、重复绑定和换槽不复制物品或重置冷却。支持原生拖放整理和快捷绑定、右键解除绑定；满背包返回未能装入的数量。

独立主动技能尚未定义，本轮没有新增冲锋或无敌。首版固定装备连发火枪，保留独立武器资源与状态组件；尚未提供第二把武器或装备切换界面。

## 控制、战斗和舒适性

`HeroUnit` 复用 `BattleUnit` 的生命、RTS 指令、导航与护甲结算。两种视角操作同一实体，`HeroWeaponRuntime` 是唯一弹匣、冷却和装填时钟。反复攻击指令、F5 和编辑外观不加速射击。

原生射线从准星决定瞄准点，再检查站立逻辑枪口至瞄准点、身体至枪口的近段。墙、石头、建筑和友军挡枪；友军不受伤。跳跃或枪管长度不能帮助穿墙。RTS 目标被挡住时沿现有导航接近，不持续向墙耗弹。真实伤害与烟迹、粒子和表现池独立。

身体与所有饰品统一位于第 19 可见层，第一人称相机排除该层。专用武器视口只有火枪。平地走路默认固定眼高，无受击震屏、转向侧倾或开枪镜头抖动。

已实现设置：水平 FOV 90°（70°–110°）、CS2 刻度鼠标灵敏度 1.0（0.05–20.0）、反转纵向、行走起伏（默认关闭）。灵敏度可通过滑杆或原生数值框精确输入，步长 0.01。按视口比例将水平 FOV 换算为 Godot 垂直 FOV。未提供额外准星样式或镜头震动强度设置。

鼠标转角为 `原始移动计数 × 灵敏度 × 0.022°`，对应 CS2 默认 `m_yaw / m_pitch` 的未开镜尺度；相同 DPI 和默认轴倍率下保持相同转身距离，视觉观感仍由 FOV 决定。Godot 鼠标捕获模式使用 `screen_relative`，不乘帧时间、视口缩放或 FOV 系数，不添加加速或平滑。旧设置按 `旧值 × 0.002 / deg_to_rad(0.022)` 等效转换（例如 0.35 → 约 1.82）；保存时记录 CS2 单位，避免重复转换。新安装和恢复默认均为 1.0。依据：[CS2 控制台变量记录](https://gist.github.com/saul/8a4c35f51eab096f7fdcdca1ef994cb4)、[Valve 鼠标输入源码](https://github.com/ValveSoftware/source-sdk-2013/blob/master/src/game/client/in_mouse.cpp)、[Godot 未缩放鼠标输入](https://docs.godotengine.org/en/4.6/classes/class_inputeventmousemotion.html#class-inputeventmousemotion-property-screen-relative)。

跳跃持续 0.65 秒，最高抬升 0.45 米，只改变模型与镜头表现。逻辑位置、碰撞、攻击距离和受击判定维持原位，不能翻越障碍或躲避攻击。

第一人称已补充蓝天、低多边形白云与浅蓝地平线，支持完整转向与仰视。天空显示和既有环境光照分开，保留 RTS 的暖色照明；原生静态天空不需要每帧计算云层。资源与验证记录见 `assets/sky/README.md`。

| 路径 | 用途 |
|---|---|
| `assets/models/heroes/capsule.tscn` | 可编辑身体、表情、饰品与动画 |
| `assets/models/heroes/capsule/` | 分件 GLB、原生 ArrayMesh、面数记录 |

| `scenes/hero/` | 实体、控制器、创建、背包、HUD、物品格 |
| `scripts/hero/` | 拥有关系、控制、武器、形象与背包逻辑 |
| `data/sandbox/` | 沙盒英雄、武器、药剂数据 |
| `assets/ui/hero/` | 透明主题、原生样式和图标 |

只重建英雄模型：

```powershell
python tools/build_hero.py
& 'C:/Program Files/Godot/Godot_console.exe' --headless --path . --script tools/build_hero_meshes.gd
```

重建原生界面和主题：`python tools/build_hero_interface.py`。不运行会重写旧兵种的默认全量导出。

英雄不加入普通招募或线上单位允许列表。`data/sandbox/` 明确排除在 relay 内容指纹之外；今后开放联机时，须将相关规则纳入网络契约并实现权威控制。本轮不部署线上服务，也不重写已有的地图、内容清单等工作区修改。

- `hero_combat_flow_test.gd`：18 项通过。实际物理帧下连续射击间隔约 0.633 / 0.667 秒、平均约 0.65 秒，空弹匣后间隔 1.8 秒；覆盖友军挡枪与固定眼高。
- `hero_geometry_test.py`：2 项通过。采样脸面顶点与三角形内部，确保曲面处在身体表面外侧，没有明显悬空。
- `content_manifest_test.py`：通过。沙盒规则不改变线上指纹，常规单位和地图修改仍改变指纹。
- 现有回归：设置 151 项、战斗数值 82 项、真实设置与退出流程 60 项通过。设置覆盖灵敏度精确输入、原生滑杆同步、直接点击应用、保存恢复和旧刻度的一次性换算。旧设置流程测试增加等待场景揭幕完成后再输入及退出，避免加载遮罩截获测试事件或转场协程未结束就退出。
- Vulkan 实际渲染检查：默认脸、六种表情、帽子与配件、正背侧面、开火和装填、战场同屏、第一人称、背包、设置。检查 1280×720、1280×800、1920×820 窗口布局。
- 验证图只写入忽略目录 `.local/hero/current/` 并覆盖旧版，交付时只保留必要展示图。
