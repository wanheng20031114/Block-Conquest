# MOBA 林地地表

2026-09-19 使用 ImageGen 生成的原创手绘地表素材，供 `moba/test1` 使用。
原图为 1254 × 1254 的四宫格；按四个等大的 627 × 627 区域无损切分，未拉伸、重绘或推断透明度。

- `meadow.png`：短草、苔藓和三叶草。
- `earth.png`：压实泥土与嵌入的小石粒；也为三维铺路石提供低强度磨损纹理。
- `woodland.png`：林下腐殖土、落叶与苔藓。
- `flagstone.png`：建筑庭院石铺。

导入设置开启 mipmap 和高质量 VRAM 压缩；地面材质使用各向异性过滤。
草地采用镜像采样、不同尺度旋转采样及原生 NoiseTexture2D 的缓慢色差，降低接缝和重复感。
完整设计稿与验证截图不放入素材目录；运行时只使用这四张纹理和已保存的原生模型、材质。
