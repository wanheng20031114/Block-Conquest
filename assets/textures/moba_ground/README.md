# MOBA 林地地表

2026-09-19 按“减少细节、减少杂色、偏可爱的方块风格”反馈，使用 ImageGen 重新绘制的原创地表素材，供 `moba/test1` 使用。
原图为完全不透明的 1254 × 1254 四宫格；按四个等大的 627 × 627 区域无损切分，未拉伸或使用代码重绘。

- `meadow.png`：柔和草绿底色与少量几何色块。
- `earth.png`：奶油米色土路与浅色方块。
- `woodland.png`：同一绿色系中略深的林下色块。
- `flagstone.png`：大块、干净的暖灰石铺。

导入设置开启 mipmap 和高质量 VRAM 压缩；地面材质使用各向异性过滤。
地面材质以统一色板混合低对比度方块纹理，镜像采样处理接缝；NoiseTexture2D仅提供约±2%的缓慢明暗变化。
三维铺路石改用原生StandardMaterial3D的纯色与倒角，不再采样磨损纹理。
完整设计稿与验证截图不放入素材目录；运行时只使用这四张纹理和已保存的原生模型、材质。
