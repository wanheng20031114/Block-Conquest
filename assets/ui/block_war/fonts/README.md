# 积木战争数字字体

Inter 可变字体来自 [Google Fonts / Inter](https://github.com/google/fonts/tree/main/ofl/inter)，随附原始 SIL Open Font License。字体文件随游戏分发，数字外观不依赖系统安装字体。

`numbers.tres` 使用 600 字重、14 光学字号及等宽数字（tabular figures）。资源中的 OpenType 整数标签分别为 `wght` = 2003265652、`opsz` = 1869640570、`tnum` = 1953396077。使用整数标签保证 Godot 的原生变体实际应用这些值。MSDF 支持世界空间人口标牌随镜头缩放。
