# 地图草地、水面与日光美化

本次以积木战争的六张地图为主，一般模式的六张地图沿用同一套色块草甸方法，采用更暖的配色。建筑、地形通行范围、桥面和地图布置保持原有数据。

## 视觉处理

- 草地：原生 `FastNoiseLite` / `NoiseTexture2D`，世界坐标采样，宽尺度色块、中尺度轮廓扰动、少量细节共同形成三层草色。避免每个地块重复贴图和满屏细碎噪点。细小草叶标记用像素导数抗锯齿，拉远时渐隐。
- 水面：两层方向与尺度不同的原生噪波法线，慢速流动、青绿浅滩、较深湖心、稀疏细长亮纹。原生 SSR 接收石桥和岸边不透明物体的反射，天空辐射提供环境反射。
- 岸线：四张后续水域地图保留单一、不重叠的水网格；采样间距从 1.5 米细化到 0.75 米。顶点 `COLOR.r` 保留原浅水权重，`COLOR.g` 存储到真实岸线的距离 / 8，支撑连续的浅滩与泡沫。裂谷使用与既有岸线一致的解析距离。
- 岩岸：浅色干燥岩面向水线附近较深的湿润色过渡，同时改变粗糙度。
- 光照：暖日光、偏冷天空环境光、较轻的接触遮蔽、收紧阴影偏移。天空 shader 使用静态云层，不引用 `TIME` 或相机位置，避免每帧重建反射立方体。
- 一般模式：原有 Earth 网格绑定草甸材质，Stone 网格中的石路、道路肩部和铺装保持可辨识；减轻棕黄色雾和过深的环境遮蔽。

所有运行时表现通过保存的场景、材质与 shader 实现，没有增加动态生成的场景节点或图片素材。地图生成器同步维护资源绑定，后续重建不会覆盖本次风格。

## 调整入口

| 项目 | 文件 |
| --- | --- |
| 色块形状、草叶密度 | `assets/block_war/environment/meadow_surface.gdshaderinc` |
| 噪波资源 | `assets/block_war/environment/meadow_noise.tres` |
| 积木战争配色与道路过渡 | `map_ground.gdshader` / `forest_ground.gdshader` |
| 水色、流速、法线、亮纹、反射比例 | `assets/block_war/environment/water_surface.gdshaderinc` |
| 岸线距离烘焙 | `tools/bake_block_war_shores.gd` |
| 岩岸干湿变化 | `assets/block_war/environment/shore_rock.gdshader` |
| 天空与 SSR | `daylight_sky.gdshader` / `woodland_daylight.tres` |
| 一般模式草甸配色 | `assets/models/environment/skirmish_meadow.gdshader` |

水面保持不透明，以适配当前正交视角和原生 SSR。没有实现透明水下折射。SSR 受屏幕范围限制，只反射可见的不透明物体；屏幕外使用天空反射，不能把它当作完整的平面镜。一般模式现有六张地图没有水域，本次水面效果应用于积木战争。

## 参考资料

实际查阅并采用其原理，shader 为本项目自行编写：

- [Godot：环境、SSR 与 SSAO](https://docs.godotengine.org/en/stable/tutorials/3d/environment_and_post_processing.html)：不透明材质进入原生 SSR；深度/屏幕纹理会改变渲染通道。
- [Godot：ReflectionProbe](https://docs.godotengine.org/en/stable/tutorials/3d/reflection_probes.html)：探针与 SSR 的分工，以及每帧重绘的成本。本次开放战场采用天空反射与 SSR。
- [Godot：天空 shader](https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/sky_shader.html)：静态云层辐射、避免不必要的 cubemap 更新。
- [Godot：Noise](https://docs.godotengine.org/en/stable/classes/class_noise.html)、[FastNoiseLite](https://docs.godotengine.org/en/stable/classes/class_fastnoiselite.html)：无缝噪波与域扭曲。
- [Absorption Based Stylized Water](https://godotshaders.com/shader/absorption-based-stylized-water/)：分层法线、岸边泡沫、粗糙度与反射的组合。
- [Stylized Water with Depthfade](https://godotshaders.com/shader/stylized-water-with-depthfade/)：浅深水混色思路；该实现为旧版 Godot，本项目没有直接移植旧的深度还原公式。

## 验证记录

Godot 4.6.3，Forward+，Windows，RTX 3080 Ti，1600 × 900。

- `tests/block_war_map_authoring_test.py`：10 项通过，桥面、接缝、通行宽度、道路连接。
- `tests/block_war_maps_test.gd`：六张地图共 5,203 项通过，2,306 对建筑路线全部连通，完整队列足迹没有离开可通行地面。
- `tests/block_war_test.gd`：43 项通过。
- `tests/skirmish_maps_test.gd`：106 项通过。
- `tests/block_war_maps_visual.gd`：六张总览、桥头/中央石台/岛屿接缝细节、固定镜头间隔与相机微移截图，以及三页选图界面。
- `tests/block_war_surface_visual.gd`：四张近景、SSR 开关对照、水面流动与暂停断言、GPU 帧耗时采样。
- 一般模式的全图对照与真实出生点截图，检查草甸、道路、战争迷雾与建筑阴影。
- 内容清单已重建，`python tools/build_content_manifest.py --check` 通过。

林湖近景静止场景的最终采样：GPU 中位约 1.55 ms；宿主设置为 120 FPS，整帧中位约 8.33 ms。采样关闭了 AI 并隐藏部分 UI，且设备由多个任务共享；它用于排查明显渲染回退，不代表完整战斗性能或可靠的 SSR 增量成本。

截图存于本机 `artifacts/map_style/` 与 `artifacts/block_war_maps/`；基准图存于 `artifacts/map_style/before/`。验证期间工作区并行修改的 `bulwark.gdshader` 出现 `CLEARCOAT_GLOSS` 编译错误；地图材质没有此错误，该技能文件不属于本次修改。

复查可运行：

```powershell
Godot_console.exe --path . --audio-driver Dummy --script tests/block_war_surface_visual.gd
Godot_console.exe --path . --audio-driver Dummy --script tests/block_war_maps_visual.gd
```
