## 必须保留

`.gitignore` 只控制主仓库对未跟踪文件的收录，不代表这些文件没有价值，也不保证可以重新生成。部署私钥应当被 Git 忽略，但仍需保留；嵌套的 Git worktree 有自己的暂存区，外层目录被忽略并不能保护其中未提交的修改。当前 `.local` 混放了可丢弃产物、持久部署数据和开发工作树，因此不能将整目录视为缓存。这是目录职责混杂，而不是 Git 忽略规则的例外。

- `.local/network/relay-private.key`：部署私钥，1,675 字节。本轮只检查文件元数据，未读取内容。
- `.local/network/endpoint.json`：部署端点配置，69 字节。
- `.local/cavalry-navigation-20260912`：129,296,504 字节，包含仍登记且有未提交代码／测试／报告的 Git worktree，整体保留。
- `artifacts/.gdignore`：防止以后生成的测试截图被 Godot 导入，清理脚本保留或重建该标记。

排除这些内容，可清理约 **22,986,931,059 字节，即 21.408 GiB（22.99 GB）**。这只是已核实的文件内容大小；文件系统实际可用空间变化可能受分配单元和同时发生的磁盘活动影响。
