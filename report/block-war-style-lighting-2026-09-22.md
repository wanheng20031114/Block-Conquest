# 积木战争：阵营屋顶、统一材质与光照

用户反馈建筑与地图风格不一致，并要求屋顶明确使用阵营色。本次保留建筑、树木、石块和单位的全部几何与尺度，仅调整材质、归属色与光照。

## 变化

- 住宅与铁匠铺屋顶随归属显示橙金、青绿或中立砂灰。实例着色保留原瓦片深浅，墙、木门和金属不染色；占领、改建时同步更新。
- 建筑白石与金饰转为暖灰石、棕木、旧铜，增加粗糙度并收敛金属高光；源 GLB、原生网格与离线构建器配色一致。
- 桥面与栏柱使用暖灰石，地面减少黄绿色，土路改暖灰，河水改灰青并弱化泡沫/镜面反射。河岸颜色统一通过 `source_color` 转换。
- 主场景与两套模型预览共用 `woodland_daylight.tres`，避免预览和实际战场使用不同环境色。太阳强度 1.16→0.92，反射强度 0.6；Filmic 白点 1.6，去除额外对比度/饱和度增益。调整天空色、接触阴影及投影偏移，保留轮廓与材质层次。
- 炉火发光 2.6→1.6，局部灯及整段闪烁动画同步缩至原来的 65%，防止动画覆盖静态灯光设置。

## 验证

Godot 4.6.3 / Forward+ / Windows / RTX 3080 Ti。

- 核心玩法：`block_war_test.gd`，39 项，0 失败。
- 屋顶：`block_war_roof_factions.gd`，中立/双方阵营、占领、类型切换、相邻实例隔离、墙体不染色和炉火峰值通过。
- 原生渲染：默认全景、双方行军、桥头、林缘、三建筑、四树种和岩石截图复核，无脚本或着色器错误。炮口跟随、瞄准、后坐、底座固定和动画暂停检查通过。
- 地图 350 个节点及其属性与修改前完全相同，地图生成器输出幂等。人口、产兵、技能、AI、路线、碰撞、缩放和编队未修改。
- 1600×900、关闭垂直同步、8 秒采样：平均 **4.76 ms/帧**，P95 **5.77 ms**，可见民兵峰值 **992**。同机前一版平均 4.75 ms，P95 5.59 ms；单次采样性能接近，不代表其他显卡帧率。
